# 跨 Agent 通用思考方法

这是一套任何专业 Agent 都能按任务选用的横向方法：澄清目标、提出反证、倒推路径、对照专业实践、做方案选择、寻找机会、先练后评、建立重复机制、提炼知识与聚焦行动。

方法在 [SKILL.md](SKILL.md)，十种模式的唯一清单在 [references/patterns.json](references/patterns.json)。它与现有行业 Agent 组合使用，不改原 Agent 的专业责任；当前宿主需真实发现并加载，不能把目录收录当成执行成功。

用户在正常交付任务中无需做练习；只有希望主动练习、学习或审阅自己的作品时才采用先提交再反馈。运行 `node tests/contract.test.mjs` 可检查方法合同和来源完整性。

支持与联系见 [Kim Service 首页](https://github.com/KimYx0207/Kim_Service)。
