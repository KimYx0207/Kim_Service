# 检索质量评估交付示例与工作单

## 已完成的教学示例

以下输入为合成案例，数字和状态用于演示复核方法。

```json
{
  "dataset": {
    "q1": [
      "a",
      "c"
    ],
    "q2": [
      "z"
    ]
  },
  "runs": {
    "q1": [
      "b",
      "a",
      "a"
    ],
    "q2": []
  },
  "policy": "k=3，P@k分母固定3，重复ID仍占位置"
}
```

- **metrics**：q1命中1，P@3=1/3，Recall@3=1/2，MRR=1/2；q2三项为0。宏平均Recall=0.25，MRR=0.25。
- **slices**：2题，仅演示公式；不能推断生产表现。
- **diagnosis**：q1缺c且重复a占位；q2无召回，分别查切块/去重与过滤。
- **nextExperiment**：保持索引语料固定，先改变去重策略后在留出题复查。

## 为什么退回这一份

重复ID虚增召回：{"metrics": "q1返回两个a，因此命中2/2，召回100%。"}

错误原因：相关文档ID只命中a一个。

## 可以继续的局部结果

没有标签：{"metrics": "gold为空的题Recall为null，单列无标签数量，不并入宏召回平均。"}

未标注不是完美表现。

## 用于当前任务的工作单

| 交付项 | 本次应填内容 | 检查方法 |
| --- | --- | --- |
| metrics | 明确P@k/Recall@k/MRR定义，去重文档并保留空结果和无标签情况。 | deterministic_recompute |
| slices | 按问题类别、语言和权限比较同题版本，报告分子分母。 | deterministic_recompute |
| diagnosis | 区分缺文档、过滤、召回、排序和标注错误，回读原文。 | source_check |
| nextExperiment | 每次改变可解释因素，保留基线和独立留出题。 | artifact_inspection |

用真实输入替换示例并保存产物位置。关键业务错误只阻断受影响的结论或操作；格式和解释完善不要求全任务停下。
