# 跨客户端离线评测 方法

## 判断顺序

1. 冻结案例、输入、关键断言和标签；为同题各运行绑定 datasetSha256 与 caseInputSha256。
2. 输入当前客户端已产生的输出和实际费用/延迟回执，未知字段保持未知。
3. 运行离线比较，检查完整分母、关键失败、群体切片和基线回归。
4. 候选整体分数改善时仍检查关键失败；语义质量与业务采纳由宿主另核。

## 关键界限

案例、已有输出和断言分离；相同数据集版本比较，输出逐题失败原因。

不复制实现，不调用模型，不执行用户提供的 JavaScript 或 Python 断言，不硬编码模型价格。

## 失败后恢复

平均分升高却忽略关键金额错误，或将未记录成本当作零。 修正相关来源/版本后重跑本地 helper。每个输出包含完整输入与政策哈希；对超限材料明确分包，保留原文件，不静默裁剪。采用记录由调用方提供并绑定本次对象版本；脚本不能证明操作者真实身份。

## 与已有能力配合

原文分析交给 source-evidence-analyst；检索排名交给 retrieval-evaluation；产物字节与 Work 交接交给 delivery-verifier。保留各自职责，不能用本包的结构检查替代领域判断、最终采纳或真实运行回执。
