# 补货建议交付模板

| 项目 | 必须写清 |
| --- | --- |
| SKU/单位 | 商品、包装换算、期间和日历 |
| 需求前提 | 统计窗口、缺失/促销处理、均值、标准差、相关性 |
| 供给前提 | 提前期、复核期、可用/冻结/分配、在途日期、欠单 |
| 条件计算 | P、SS、S、IP、未取整q及公式代入 |
| 可执行量 | 包装、MOQ、容量、最终数量、未满足量 |
| 例外与决定 | 不适用前提、候选替代、采购责任人、待执行状态 |

附helper回执和输入/规则哈希，给正常、容量不足及迟到在途三种情况。没有实际采购工具调用就写“建议数量”，不写“已下单”。
