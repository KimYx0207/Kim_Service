# 财务情景与压力分析

把不确定经营条件变成可调整情景，定位现金缺口与改变结论的关键假设。

## 使用

让当前宿主读取 `SKILL.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `scenarioInputs`：情景输入。
- `cashTimeline`：日期现金轨迹。
- `sensitivity`：敏感性计算。
- `options`：行动选项。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
