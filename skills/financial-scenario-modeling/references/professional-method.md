# 财务情景与压力分析工作方法

## 目标与执行

把不确定经营条件变成可调整情景，定位现金缺口与改变结论的关键假设。

1. 统一现金口径、币种和时间粒度，区分实付与预计。
2. 按日期排列收付，计算滚动余额及首次低于约束的时点。
3. 建立基准和下行情景，将每个变化映射回原始驱动。
4. 单独运行敏感性，按明确现金流时点重算NPV或简单跑道。
5. 提出延后支出、分阶段投入等可审查选项，显示各自影响和依赖。

## 关键判断

- 当期末余额为正：仍检查途中最低点；避免只看期末。
- 当计算NPV：t0与未来期末分开；避免把期初投入再次折现。
- 当流出变化：按当前情景和期限估算；避免用一个月净值保证长期生存。

## 领域细节

随包计算器处理等间隔期末现金流NPV和按明确序号的滚动现金余额；不推断税、汇率或投资适当性。金钱精度由实际币种决定。若收入和成本有相关关系，应联动建立情景并解释，不能把两个极端随意拼成概率预测。

## 输入不全时

- `baseline`：期初现金和按日期列出的收付款。可先交现金流结构，未知到账不能当已收。
- `drivers`：变化因素、范围、依赖和币种。标明独立敏感性与联动情景。
- `constraints`：最低现金、期限、折现口径和决策目标。缺阈值可报告结果范围，不擅自认定可承受。

缺少非关键资料时，先给明确假设下的草案或局部结果；资料补齐后只重验受影响部分。授权已覆盖的可逆工作继续，不重复确认。

## 参考方法的用途

- Aswath Damodaran valuation spreadsheets：匹配现金流类型和折现率，分开经营价值与股权价值。
- SEC EDGAR APIs：保留财报来源、期间、单位、申报日期与版本，回读原文核对口径。

出处和适用边界见 [PROVENANCE.md](../PROVENANCE.md)。本包方法、案例和工作单为原创整理。

## 可运行参考计算
