# 分阶段图解 方法

## 判断顺序

1. 从真实系统说明提取阶段、节点、分支、返回路径与来源，人工判断内容是否准确。
2. 执行图数据校验，拆开超过五个并排节点的阶段。
3. 生成 SVG、storyboard.html 和文字替代文本；首尾沿共同中轴布局。
4. 逐阶段检查解释和关联，宿主有浏览器时再做实际渲染检查。

## 关键界限

按阶段逐步显现，保留静态全图、键盘操作和减少动态效果的选择。

不复制实现，不用图生绘制精确架构，不声称动画代表真实执行；本版只支持有界分层布局。

## 失败后恢复

缺少节点仍生成伪连线，或用播放状态冒充运行回执。 修正相关来源/版本后重跑本地 helper。每个输出包含完整输入与政策哈希；对超限材料明确分包，保留原文件，不静默裁剪。采用记录由调用方提供并绑定本次对象版本；脚本不能证明操作者真实身份。

## 与已有能力配合

原文分析交给 source-evidence-analyst；检索排名交给 retrieval-evaluation；产物字节与 Work 交接交给 delivery-verifier。保留各自职责，不能用本包的结构检查替代领域判断、最终采纳或真实运行回执。
