# 血缘影响交付模板

1. 变更：对象全限定ID、旧/新语义、环境、版本、计划窗口。
2. 输入：目录/SQL/作业日志的来源、采集日期、未覆盖系统。
3. 影响表：下游ID、直接/间接、完整路径、observed/possible、证据位置、责任人、具体风险。
4. 回归表：场景、输入快照、预期不变量、实际结果、偏差、复核人；未跑写未观察。
5. 例外：未知变更ID、循环、失效引用、无责任人、图外导出。
6. 变更建议：顺序、监测、回滚触发；不得把helper completed写成批准上线。

附原始helper回执。抽查至少一条直接和一条间接路径，按源证据确认方向，复算inputSha256和policySha256。
