# 教学评价设计交付示例与工作单

## 已完成的教学示例

以下输入为合成案例，数字和状态用于演示复核方法。

```json
{
  "objectives": "能用单位成本解释盈亏平衡",
  "tasks": "售价50、变动成本30、固定成本2000的合成店铺",
  "constraints": "可用文字或语音解释，不以写作速度评分"
}
```

- **alignment**：要求计算并解释卖出100件时为何刚好覆盖固定成本；再问降价后的变化。
- **rubric**：2分：算出100件并解释每件贡献20；1分：算对但解释缺；0分：混淆收入与贡献。
- **feedback**：你把售价当贡献了；先用50−30求20，再用2000÷20，换一组成本重做。
- **fairness**：允许口述计算过程；评分依据计算和解释，不依据字体或语速。

## 为什么退回这一份

背诵代替应用：{"alignment": "能背定义就判定掌握所有商业定价应用。"}

错误原因：任务证据不足以支持迁移能力。

## 可以继续的局部结果

评分分歧：{"rubric": "两位评分者对解释项有分歧，回到作品证据补等级锚点再复评。"}

评分需可复核而不是盲目平均。

## 用于当前任务的工作单

| 交付项 | 本次应填内容 | 检查方法 |
| --- | --- | --- |
| alignment | 每目标有能观察对应能力的任务，分清记忆、理解与迁移。 | artifact_inspection |
| rubric | 各等级描述可观察差别，分数能由作品证据支持。 | domain_review |
| feedback | 指出已做到、具体差距及下一步可练习动作。 | artifact_inspection |
| fairness | 不让无关阅读/表达障碍替代目标能力，保留评分分歧复核。 | domain_review |

用真实输入替换示例并保存产物位置。关键业务错误只阻断受影响的结论或操作；格式和解释完善不要求全任务停下。
