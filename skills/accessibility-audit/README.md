# 可访问性检查与修复

用真实任务检查键盘、阅读器、焦点、文字和错误恢复，并把问题落实到修复位置。

## 使用

让当前宿主读取 `SKILL.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `findings`：可复现问题。
- `fixes`：修复与回归。
- `coverage`：覆盖范围。
- `priorities`：修复顺序。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
