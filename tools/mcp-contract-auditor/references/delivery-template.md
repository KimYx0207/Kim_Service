# MCP契约审计交付模板

1. 前后快照：服务身份、协议、采集时间、授权视角、分页是否完整。
2. 工具差异：name、字段名、旧/新canonical hash、可能影响的实际工作流。
3. schema范围：明确可读对象根、需检查引用/组合、未执行的validator与调用探测。
4. 授权对照：已允许名称、未批准名称、行为注解变化、真实服务信任证据。
5. 后续动作：具体需核契约或探测，不自动安装、调用或修改配置。

附原始输入与机器回执。completed仅表示本次有限比较无待核差异，liveConnectionObserved始终false；不要写已连通、已认证或已自动开通权限。
