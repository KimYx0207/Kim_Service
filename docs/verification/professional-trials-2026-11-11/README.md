# 三题同题对照记录

两个全新任务上下文分别作答同一组原创合成题。基线只接收题目；方法组可读三个指定组件的入口、合同、方法与参考。两组各一次，均使用本会话继承的模型；未额外调用 CLI 模型、外部模型 API 或真实账户。具体内部模型版本与随机种子未暴露，不能声称受控的跨模型实验。

[题目](tasks.json) · [试验前写好的检查标准](prespecified-criteria.json) · [基线原答复](baseline.md) · [方法组原答复](with-methods.md) · [读取材料清单](sources-read.json) · [逐项评审](review.md) · [逐项机器记录](review.json) · [公开副本哈希说明](publication.json)

**结果：两组都是 3/3 题、37/37 条预设标准通过；本次可观察正确率差为 0 个百分点。** 26 项数值、11 项判断由另一任务上下文重新计算、逐段核对，主线程复核关键数字与结论。评审者不是盲审外部机构，题目也不是随机行业样本。

这没有检出方法包的正确率提升，不能宣传“用了就比模型更专业”。同样，它不证明方法包在其他任务无效或普遍等效。更长的答案不是独立质量得分；资源读取清单的自述不能代替第三方工具读取回执。没有评估时间、token成本、真实客户结果，也没有在 DSh 里调用 DeepSeek 模型。

后续有效性评估需要对每个实际领域补充真实且脱敏的任务、独立领域评审、重复运行、模型与资源版本绑定，比较关键错误、交付可用性与成本；在这些观察完成前，各包保持 `professionalEffect: not_evaluated`。
