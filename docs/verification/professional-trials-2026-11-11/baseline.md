# 一、原价与八五折的报价分析

**按已提供的成本计算，原价90元每月交付68单起可以覆盖成本；八五折后的76.50元需要每月100单才能覆盖成本，超过每月90单的交付上限。** 因此，八五折不能作为目前成本和容量条件下可独立实现收支平衡的常规报价。

以下金额均为人民币。这里的“余额”指扣除题目所列材料、劳动、包装、平台费用和固定费后的余额。劳动已明确估值为18元/单，必须计入成本；税费、获客、退货等没有资料，因此下表不是完整净利润预测，也不代表实际需求能达到满容量。

## 1. 单位经济

八五折售价：

\[
90\times85\%=76.50\text{元/单}
\]

不含平台费的单位变动成本：

\[
22+18+5=45\text{元/单}
\]

平台费按实际收款计提，不能把原价对应的平台费直接套用在折扣价上。设实际收款单价为 \(P\)，则：

\[
\text{单位贡献}=P-7\%P-45=0.93P-45
\]

“单位贡献”是每成交一单可用于覆盖固定费的金额，覆盖完固定费后才形成上述口径的余额。

| 项目 | 原价 | 八五折 |
|---|---:|---:|
| 实际收款单价 | 90.00元 | 76.50元 |
| 材料 | 22.00元 | 22.00元 |
| 劳动 | 18.00元 | 18.00元 |
| 包装 | 5.00元 | 5.00元 |
| 平台费：单价×7% | 6.300元 | 5.355元 |
| 单位变动成本合计 | 51.300元 | 50.355元 |
| **单位贡献** | **38.700元** | **26.145元** |
| 单位贡献÷收款单价 | 43.00% | 34.18% |

为便于复算，单位平台费和贡献保留三位小数，汇总后再按分展示。平台若逐单按分结算，实际金额可能出现小额舍入差异，具体规则尚未提供。

## 2. 月盈亏平衡量与满容量余额

将季度固定费均摊到三个月，用于比较月度经营表现：

\[
\text{月固定费}=7800\div3=2600\text{元}
\]

这是一种经营分析口径，不代表固定费实际按月支付。月度余额公式为：

\[
\text{月余额}=\text{当月交付并收款的订单数}\times\text{单位贡献}-2600
\]

盈亏平衡量需要向上取整，不能向下取整或四舍五入：

| 项目 | 原价 | 八五折 |
|---|---:|---:|
| 理论月盈亏平衡量 | 2600÷38.7＝67.1835单 | 2600÷26.145＝99.4454单 |
| **实际需要的整数订单量** | **68单/月** | **100单/月** |
| 在90单/月容量内能否达到 | 能，但需要足够需求 | 不能 |
| 满容量月收款：90×单价 | 8,100.00元 | 6,885.00元 |
| 满容量月材料、劳动和包装：90×45 | 4,050.00元 | 4,050.00元 |
| 满容量月平台费 | 567.00元 | 481.95元 |
| 满容量月贡献 | 3,483.00元 | 2,353.05元 |
| 月固定费 | 2,600.00元 | 2,600.00元 |
| **满容量月余额** | **＋883.00元** | **－246.95元** |

如果连续三个月都交付并收款90单，季度合计270单，则原价的季度余额为 **2,649.00元**，八五折为 **－740.85元**。这仍然只覆盖已列明的成本口径。

## 3. 条件式经营建议

- **如果原价实际需求能稳定达到每月68单以上，优先保留原价。** 在当前成本模型中，68—90单可以形成正余额；未知费用还会消耗这部分余额。原价满容量时每月只有883元空间，不能据此承诺完整净利润。
- **如果目的是让八五折常规报价覆盖全部已知成本，需要先改变成本或容量条件。** 在90单时，每月还差246.95元；等价地，需要月固定费下降246.95元，或每单非平台变动成本下降约2.7439元，或由其他明确、可持续的贡献补足。若保持当前单价和单位成本，则至少需要100单/月，已经超过现有容量，扩容还可能带来新增成本。
- **如果只考虑限时促销，应比较实际可实现的销量，而不能假定降价必然带来足够订单。** 固定费相同时，八五折要追平原价的贡献，销量至少需要达到原价销量的 \(38.7\div26.145\approx1.4802\) 倍，即增加约48.02%。例如，原价若只能卖60单，月余额为－278元；八五折若确实能卖满90单，月余额为－246.95元，只改善31.05元，仍未覆盖全部已知成本。该例只是条件演算，不是需求预测。

还可反推一个报价参考：在每月恰好卖满90单、其他已知成本不变时，覆盖已知成本的最低单价满足：

\[
P\ge\frac{45+2600/90}{0.93}=79.450418\ldots\text{元}
\]

若按分报价，至少为 **79.46元/单**。这个价格没有为未知成本、需求不足或经营利润预留空间，因此只能作为满容量条件下的已知成本下限。

# 二、两份供应商报价比较

**当前没有一份报价已被证实满足“7个自然日内到货”的硬性要求。** A承诺8个自然日到货，明确超期；B只承诺5个工作日发货，到货时间不能据此确定。价格比较可以先完成，但目前不宜据此直接确定供应商。

以下按题目给定的同税口径、同规格比较，并按整包采购计算。MOQ是最低起订量，采购量需要同时满足需求量、MOQ和包装整数倍。

## 1. 实际采购量和已知现金支出

最小采购量公式为：

\[
\text{采购量}=\left\lceil\frac{\max(\text{需求量},\text{MOQ})}{\text{每包件数}}\right\rceil\times\text{每包件数}
\]

| 项目 | 供应商A | 供应商B |
|---|---:|---:|
| 需求量 | 640件 | 640件 |
| 每件报价 | 8元 | 9元 |
| MOQ | 800件 | 600件 |
| 每包数量 | 100件 | 120件 |
| 采购量计算 | ⌈800÷100⌉×100 | ⌈640÷120⌉×120 |
| **实际最小采购量** | **800件，8包** | **720件，6包** |
| **较需求多购** | **160件** | **80件** |
| 货款 | 800×8＝6,400元 | 720×9＝6,480元 |
| 运费 | 240元 | 未报价，记为F元 |
| **已知现金支出及总额表达式** | **6,640元** | **已知货款6,480元；完整支出为6,480＋F元** |

B不能只采购640件，因为640不是120的整数倍；也不能只采购600件，因为不够本次需求。A虽然标价更低，但最低起订量导致多购更多。多购品的后续利用价值、保管成本等资料未提供，不能直接把它们认定为浪费或收益。

## 2. 运费改变现金支出比较的阈值

两家总现金支出的差额为：

\[
\text{B总额}-\text{A总额}=(6480+F)-6640=F-160
\]

| B运费F | 总现金支出比较 |
|---|---|
| 小于160元 | B更低，低160－F元 |
| 等于160元 | 两家均为6,640元 |
| 大于160元 | A更低，低F－160元 |

**160元是运费阈值，B的运费未知不能按0元处理。** 这里比较的是满足本次数量需求所需的整批现金支出；它没有给剩余库存估价，也没有包含尚未披露的其他费用。

## 3. 到货判断

| 项目 | 已有承诺 | 对7个自然日内到货的判断 |
|---|---|---|
| A | 8个自然日到货 | 在相同计时起点下，超过要求1天，现报价不满足要求 |
| B | 5个工作日发货 | 无法确认满足：工作日不能直接当作自然日，发货也不等于到货 |

B的到货日需要依次确定订单生效日期、工作日历和节假日安排、发货期限的计时规则，以及运输所需时间。即使能在第5个工作日发货，也无法仅凭这句话推定会在第7个自然日前送达。

## 4. 当前可用建议

**先按交付要求筛选，再按总支出比较。** 当前A属于明确不满足现有交期，B属于交期尚未核实，不能把“尚未核实”当成“可以按时交付”。

可把B保留为待核实备选，因为其最小采购量为720件，比A少压80件库存。后续若继续推进，需要补齐B的全包运费、明确订单计时起点和最迟到货日期，并取得满足7个自然日要求的到货承诺。若B能够确认按时到货，再根据6,480＋F元的完整报价判断是否符合预算。

若B运费超过160元，只能说明其整批现金支出高于A现报价，**不能因此改选已知会超期的A**。如果希望保留A，需要另行取得满足7个自然日到货的新方案及完整费用；新报价应重新比较。若两家都无法确认满足期限，应另找可以明确承诺交付的方案，或由需求方重新决定期限。

本次仅完成比较，没有下单或联系供应商。

# 三、店铺经营复盘与对外表述审核

**本期规模增长成立，但转化率提升和利润大涨均不成立为现有数据支持的结论。** 访客翻倍，支付订单增加50%，实收增加57.5%；与此同时，订单率从8%降到6%，去重买家转化率从6%降到3.5%。本期发生过促销，但现有两期数据不能证明这些变化由促销造成。

## 1. 统一指标定义并复算

两个期间等长、去重口径一致，按给定数据直接比较。为避免“客单价”分母混用，下表同时给出订单和买家两种口径：

- **订单率**＝支付订单数÷访客数。它反映每位访客对应的订单产出，不能直接等同于有多少访客完成购买，因为同一买家可能下多单。
- **买家转化率**＝去重买家数÷访客数。
- **订单口径客单价**＝实收÷支付订单数。
- **买家人均实收**＝实收÷去重买家数。若内部把这个指标称为“客单价”，应明确标注分母是去重买家，不能与订单口径混比。

| 指标 | 上期 | 本期 | 变化 |
|---|---:|---:|---|
| 访客数 | 1,000 | 2,000 | 增加1,000，增长100% |
| 支付订单数 | 80 | 120 | 增加40，增长50% |
| 去重买家数 | 60 | 70 | 增加10，增长16.67% |
| **订单率** | 80÷1,000＝**8.00%** | 120÷2,000＝**6.00%** | **下降2.00个百分点，相对下降25.00%** |
| **买家转化率** | 60÷1,000＝**6.00%** | 70÷2,000＝**3.50%** | **下降2.50个百分点，相对下降41.67%** |
| 实收 | 16,000元 | 25,200元 | 增加9,200元，增长57.50% |
| **订单口径客单价** | 16,000÷80＝**200元** | 25,200÷120＝**210元** | 增加10元，增长5.00% |
| 买家人均实收 | 16,000÷60≈266.67元 | 25,200÷70＝360.00元 | 增加约93.33元，增长35.00% |
| 每位访客实收 | 16,000÷1,000＝16.00元 | 25,200÷2,000＝12.60元 | 减少3.40元，下降21.25% |

百分点是两个百分比直接相减；相对变化要除以上期值。例如买家转化率的相对变化为：

\[
\frac{3.5\%-6\%}{6\%}=-41.67\%
\]

因此，不能把下降2.5个百分点写成只下降2.5%。

## 2. 哪些增长可以确认

**可以确认访客、支付订单、去重买家、实收和两种口径的平均收款均增长。** 其中，订单增长50%比去重买家增长16.67%更快，因此每位买家的平均订单数由 \(80/60\approx1.33\) 单升至 \(120/70\approx1.71\) 单，增长约28.57%。

这个结果说明订单增长不能全部解释为购买人数增加；但它本身不能证明老客复购改善，也不能识别是谁增加了下单次数。判断复购需要买家跨期匹配、新老客划分及订单明细。

收入变化可以用恒等式复算：

\[
\text{实收}=\text{访客数}\times\text{订单率}\times\text{订单口径客单价}
\]

\[
\frac{25200}{16000}
=\frac{2000}{1000}\times\frac{6\%}{8\%}\times\frac{210}{200}
=2\times0.75\times1.05
=1.575
\]

这解释了“转化指标下降而实收仍增长”在算术上如何同时成立：访客翻倍、每位访客对应的订单数下降25%、每单实收增加5%，合在一起使实收增长57.5%。这是一种指标分解，不能据此认定访客增长、价格变化或促销的因果来源。

## 3. 哪些原因或经营结果不能下结论

- **不能认定促销造成收入或订单增长。** 没有随机对照，也没有提供其他可识别促销独立影响的分析。投放、渠道构成、季节、商品组合等都可能影响两期表现，目前只能说促销与这些变化在同一期发生。
- **不能认定促销造成转化率下降，也不能反过来断言促销无效。** 总体转化率下降已被数据确认，但原因仍未知。即使总体转化率下降，各渠道内部的表现也可能不同；缺少渠道拆分，不能把“流量质量变差”当作已经查明的事实。
- **不能判断利润是否增长。** 现有数据只有实收，没有成本、促销让利的完整成本、投放支出和退款信息。利润变化方向、幅度及促销投入产出比均无法可靠计算；实收增长不能代替利润增长。

后续复盘应优先补充各渠道访客和买家转化、新老客及订单明细、商品与优惠构成、成本与退款数据。若需要评估促销效果，应设计有可比对照的分析；仅继续观察促销前后两个总数，仍不足以确认因果。

## 4. 审核负责人希望使用的表述

原句：“促销让购买转化率提升50%，利润同步大涨。”

**建议不使用原句，三个关键判断都需要修正：**

| 原句部分 | 审核结论 | 可用替代口径 |
|---|---|---|
| “促销让……” | 因果关系证据不足 | “本期开展促销期间……”或“本期数据显示……” |
| “购买转化率提升50%” | 将订单数量增幅误写成转化率增幅 | “支付订单数增长50%”；同时说明买家转化率从6%降至3.5% |
| “利润同步大涨” | 缺少成本、退款等，无法计算利润变化 | “实收增长57.5%”；明确利润变化尚待核算 |

### 可对外使用的谨慎结论

> 在统计时长及去重口径一致的比较中，本期访客数由1,000增至2,000，支付订单数由80增至120，增长50%；去重买家数由60增至70，增长16.7%。实收由16,000元增至25,200元，增长57.5%，按支付订单计算的客单价由200元升至210元。与此同时，订单率由8%降至6%，去重买家转化率由6%降至3.5%。本期开展过促销，但现有数据尚不能确认促销对这些变化的独立影响；由于成本和退款资料不完整，利润变化仍需进一步核算。
