# 门店报名页交接

## 打开方式

将 `index.html`、`styles.css`、`app.js` 保持在同一目录，直接用现代浏览器打开 `index.html`。不需要安装依赖、启动开发服务器或联网。源码均为可编辑文本文件。

## 操作方式

1. 点击「填入示例」，或填写虚构的中文姓名和邮箱。两个字段都有可见标签，姓名最多 40 个字符，邮箱最多 254 个字符。
2. 保持「本次演示结果」为「成功」，点击保留的英文按钮 **Confirm this appointment and keep my details**。约 900 毫秒的本地处理中，表单、示例按钮和确认按钮会停用；重复提交事件也会被拦截。
3. 成功后显示明确结果，名单数量增加，新记录排在最上方。表单清空并将焦点移回姓名，便于继续录入。「查看更新后的名单」链接可直接跳到名单区域。
4. 将演示结果切换为「失败」后确认，可看到模拟失败状态。姓名、邮箱和名单均保留；点击「以成功结果重试」会切换为成功结果并再次运行本地演示。
5. 空字段或邮箱格式错误会显示具体字段提示，并把焦点移到第一个错误字段。修改已标错字段时会更新该字段的错误提示。
6. 右上角「深色外观」切换浅／深主题。首次打开跟随系统偏好；手动选择后保存该外观偏好。浏览器禁止本地存储时，仍可在当前页面切换主题。
7. 刷新页面后，名单恢复为原始的「示例用户A／待确认」。示例邮箱为 `user.a@example.com`。

键盘操作已按原生控件实现：Tab／Shift+Tab 移动焦点；Enter 激活按钮或提交表单；Space 激活按钮、选择单选项；方向键切换单选项。页面提供跳转链接、可见焦点样式、字段关联提示、`aria-invalid`、处理中的 `aria-busy`，以及持续存在的结果播报区域。模拟失败后焦点移至结果区，下一次 Tab 可到达重试按钮。

## 页面组织与设计变量

桌面采用表单与名单两列，800px 以下切换单列，520px 以下缩小外边距和卡片内边距。输入框使用 16px 字号，主要控件至少 44px 高；英文长按钮允许换行，姓名和长邮箱也允许折行。390px 是本次指定的窄屏目标，相关规则已写入 CSS。

`tokens.json` 记录当前 CSS 自定义变量、浅深主题色值、字体、字号、间距、圆角、控件尺寸与断点。JSON 中的设计变量已与 CSS 做逐项一致性检查。页面采用本机系统字体，无外部字体或图片依赖；图标为本地 HTML 内的 SVG。

## 示例数据边界

- 页面明确标注「离线演示」「合成数据」，保留原始中文示例姓名和「待确认」状态。
- 所有报名记录仅存在本页 JavaScript 内存中；没有网络提交、业务连接、邮件发送、统计脚本或真实预约。
- 唯一持久化项是主题偏好 `store-signup-demo-theme`。姓名与邮箱不写入本地存储。
- 所有新增记录都带「合成示例」说明。页面没有客户成果、交易数据或效果指标。
- 这是交互演示，不提供真实后台、跨页面数据保存或业务去重。
