# 财务建模分析师工作方法

## 目标与执行

把经营假设连接到利润、现金和估值，交可复算的基准及压力情景。

1. 核对原始报表日期、币种、单位和调整，先用历史数重建简化勾稽。
2. 把收入拆数量与价格，成本拆固定/变动，连接资本开支、折旧及营运资金变化。
3. 按现金流定义建立现金预测，核对利润与现金的差异及融资现金流。
4. 按任务选择估值方法，匹配折现率与现金流，显式计算终值及企业到股权桥接。
5. 运行基准、下行和单因素敏感性；重算主要公式，并解释何种假设会改变决定。

## 关键判断

- 当进行折现：匹配FCFF/WACC或FCFE/股权成本；避免混用两种价值口径。
- 当用永续增长终值：要求r大于g并说明稳定期假设；避免分母为零/负数仍输出估值。
- 当利润推现金：调整折旧、CapEx及营运资金；避免把净利润当可分配现金。

## 领域细节

建立输入、计算、输出分层，金额标币种和数量级。FCFF常从税后经营利润加折旧减资本开支与营运资金增加推导；资本结构变动不能再次作为经营现金流重复计入。终值应使用稳定期再投资与增长一致的假设。敏感性固定其他变量，情景可联动多个驱动并说明关系。

## 输入不全时

- `historicals`：原始报表、期间、币种、会计政策和调整项。可先搭驱动模型；历史缺口明确标识。
- `drivers`：销量、价格、成本、资本开支、营运资金和融资假设。用可编辑情景区间，不能默认假设为已知事实。
- `decision`：评价问题、估值时点、折现口径和情景约束。先交经营和现金结果，待定估值参数单列。

缺少非关键资料时，先给明确假设下的草案或局部结果；资料补齐后只重验受影响部分。授权已覆盖的可逆工作继续，不重复确认。

## 参考方法的用途

- SEC EDGAR APIs：保留财报来源、期间、单位、申报日期与版本，回读原文核对口径。
- Aswath Damodaran valuation spreadsheets：匹配现金流类型和折现率，分开经营价值与股权价值。

出处和适用边界见 [PROVENANCE.md](../PROVENANCE.md)。本包方法、案例和工作单为原创整理。

## 可运行参考计算

本包提供 `scripts/model.mjs`，以命名导出函数处理明确输入；运行 `node tests/calculation.test.mjs` 可复算本例和边界反例。它是局部参考算法，生产环境的权限、数据来源和完整业务路径仍按当前任务核验。
