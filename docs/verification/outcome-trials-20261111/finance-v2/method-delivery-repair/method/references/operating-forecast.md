# 12个月经营预测样板

这是原创合成示例，适合演示销量、价格、费用、应收应付和设备采购怎样影响利润与现金。它不是 DCF，也没有声称完整三表、法定报表或真实客户结果。

## 打开和编辑

直接打开 [经营预测页面](../examples/operating-forecast/index.html)，无需服务器、联网、账号或安装。修改假设即重算；完整 JSON 可修改税率、期初应收应付、12个月设备采购/融资及情景。下载输入 JSON、结果 JSON 或月表 CSV。

配置来自 `examples/operating-forecast/sample-data.js`；纯计算在 `scripts/operating-forecast.js`；展示在 `examples/operating-forecast/app.js`。改公式只改计算模块，页面和命令行复用它。数据不会自动保存或上传。

当宿主已允许本地计算时，可以把下载或构造的输入传给固定适配器：

```sh
node scripts/forecast-cli.mjs --input-json forecast-input.json
node scripts/forecast-cli.mjs --input-json forecast-input.json --format csv
```

命令把结果写到 stdout，输入错误写 stderr 并退出2。`--input-json -` 可从 stdin 接收 JSON。该工具不赋予角色写入、账户或交易权限；未实际执行时仍报告未执行。

## 公式和边界

- 收入 = 四舍五入后的销量 × 单价；变动成本由同一销量驱动。
- 月税前利润 = 收入 − 变动成本 − 固定费用 − 显式折旧；税额按正利润和输入税率计算。示例税率不是法定适用税率，零税率不能默默当未知值。
- 回款分当月与次月；付款也分当月与次月。期初应收应付在首月结清；没有坏账或库存变化模型。
- 月末现金 = 月初现金 + 回款 − 供应商付款 − 固定费用 − 税款 − 设备采购 + 明确融资。未输入的融资不自动补入。
- 融资需求来自最小月末余额；月内资金缺口、利息、增值税、税损结转和更复杂回款均没有建模。需要这些时扩充实际模型或标出缺口，不能声称样板已经覆盖。
- 单币种、12个月，按分舍入。改变币种标签不换汇。发生矛盾时先列来源、确认状态与影响，不让未接受报价覆盖已确认预算。

当前任务只做经营模型时，`valuation` 可以明确“本任务不含估值”，不要为了填字段强行追加DCF。DCF继续使用独立的 `scripts/model.mjs`。

## 检查结果应该是什么

核对实际输出的12个月、三个明示情景、回款/付款与应收应付桥接、利润和现金差异、最早缺口与最低余额。工具测试检查确定性公式和坏输入；页面仍须实际查看、改参数、试下载。即使二者都通过，专业效果仍为 `not_evaluated`；需独立真实任务对照才能判断方法包的增益。
