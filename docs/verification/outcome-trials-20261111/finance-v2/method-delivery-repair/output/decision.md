# 2027年经营预测与资金安排说明

## 结论

按已确认预算执行，**基准情景全年净利润20,316.00元，年末现金16,954.50元；但2月最低月末现金为−2,137.50元，仍存在2,137.50元的资金缺口**。全年盈利不能保证每个月都有足够的钱。乐观情景也在2月短缺483.56元；保守情景全年亏损7,075.36元，10月资金缺口扩大至8,701.79元。[主预测](forecast.json)

主预测继续使用已确认的**45元/单**变动成本作为成本基数。供应商提出的50元/单尚未签约、尚未被经营者接受，状态为`pending`；没有将其视为预算变更，也没有假设任何融资到账。[已确认预算](../inputs/confirmed-budget.json)；[供应商补充](../inputs/supplier-proposal.md)；[事实与冲突记录](facts.json)

## 预测范围与依据

预测为2027年1月至12月，共12期；金额均为**CNY元**，销量为**单**。这是给定合成预算下的经营模型，数据不是实际客户结果。起始月份沿用预算中的2027-01。期初现金12,000元、应收2,400元、应付1,200元；期初应收应付均在1月结清。固定费用每月6,200元，折旧每月200元；2月支付设备款12,000元。全部月份的已输入融资为0。[已确认预算](../inputs/confirmed-budget.json)

本月确认收入的65%本月收款、35%次月收款；变动成本全部当月支付。正的月度税前利润按20%模型税率计税并当月支付，不作亏损结转。设备支出进入现金付款，折旧进入利润费用，两者不混淆。销量每月从原始起点直接计算并四舍五入，不能对上月已经取整的销量再复利。每行金额先按`Math.round(x × 100) / 100`保留两位，后续计算使用这些金额。[计算口径](../inputs/calculation-policy.md)

## 为什么有利润仍会缺钱

基准1月末只剩9,000.00元。2月的14,692.50元回款，需要面对25,830.00元付款，其中设备支出为12,000.00元，因此2月现金减少11,137.50元，月末落至−2,137.50元。2月净利润仍为820.00元，因为设备支出并非当月全部计入利润费用。3月末现金仍为−1,095.00元，4月末才回到127.50元。[基准月度数据](forecast.json)

单独将**基准情景**的每单变动成本从45元改为50元，其余经济驱动完全不变。该测算未并入三情景主预测，未赋予报价批准状态，也未假设签约日期。[敏感性输入](sensitivity-input.json)；[敏感性结果](sensitivity.json)

## 需要做的决定与仍未确定的事项

1. **先解决2月的支付时点。** 如完全执行现有基准预算，应在2月相关支出发生前落实至少2,137.50元的资金安排，或另行批准调整收支计划。模型中的融资仍为0；资金来源、到账日和条款均未确定，未代替经营者作承诺。
2. **按承受能力检查保守情景。** 若需要覆盖本题保守情景，应把8,701.79元的全年最大月末缺口纳入安排，并持续复核销量、单价和每单成本。该金额也没有写入主表融资。
3. **明确决定是否接受50元报价。** 当前保持`pending`；确认接受金额和生效月份后，再只更新受影响期间。敏感性演示假设50元覆盖整个预测期，不能当作已约定的实施计划。
4. **先核对最影响结论的假设。** 对现金最直接的是2月设备支付日与实际回款日；对全年盈利最直接的是销量、售价和变动成本。给定材料足够完成本题模型，但未提供真实订单、合同执行或月内收支日程，不能据此声称已验证业务实现程度。

以上资金数值均按月末余额计算；月内先付款后收款可能需要更多周转资金，材料不足以量化。不要把月末缺口当作绝对安全的现金上限。[计算口径](../inputs/calculation-policy.md)；[模型边界](../method/references/operating-forecast.md)
