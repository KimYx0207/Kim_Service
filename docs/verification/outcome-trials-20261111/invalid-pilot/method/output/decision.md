# 2027年经营预测与现金安排

## 先看结论

按经营者确认的预算，基准全年收入 **204,390.00元**、净利润 **20,316.00元**，但**2027年2月会出现2,137.50元月末现金缺口**。全年盈利不能保证每个月现金够用。乐观情景同样在2月出现483.56元缺口；保守情景全年亏损7,075.36元，10月最低现金为−8,701.79元。所有主情景融资均为0，没有把尚未决定的融资补进模型。

本次按预算起始月预测2027年1月至12月；金额均为CNY元，数量为单。材料是合成资料，预算中的确认代表假设版本已确认，不代表未来经营结果已发生。[来源：已确认预算](../inputs/confirmed-budget.json)。

各情景固定费用均为6,200元/月、折旧200元/月、税率20%。当月回款65%，余款次月收回；采购当月全付，期初应收2,400元和应付1,200元在首月结清。2月设备采购12,000元；其他月份资本开支和全部融资均为0。[来源：已确认预算](../inputs/confirmed-budget.json)。乐观与保守同时改变销量、增长、价格和成本，属于多因素情景；下文才是保持其他条件不变的单因素报价敏感性。

## 为什么有利润，现金仍会不够

基准1月净利润640元，却净流出现金3,000元：14,400元收入只收回本月部分款项，加上期初应收结清后总回款11,760元；含期初应付款的供应商支出为8,400元，再支付固定费用6,200元及税160元，共支出14,760元。月末现金从12,000元降至9,000元。

2月净利润820元，但设备采购一次支付12,000元，使现金支出达到25,830元，超过14,692.50元回款，当月净流出11,137.50元，月末余额变为−2,137.50元。设备采购进入现金支出；损益只扣每月已设定的200元折旧，不能把12,000元又当作当月费用重复扣除。

全年基准利润到现金的桥接如下，逐项能与月表核对：

| 项目 | 对现金的影响（元） |
| --- | ---: |
| 期初现金 | 12,000.00 |
| 加：全年净利润 | 20,316.00 |
| 加：非现金折旧 | 2,400.00 |
| 减：资本开支 | −12,000.00 |
| 减：应收增加（6,961.50 − 2,400.00） | −4,561.50 |
| 加：应付变动（0 − 1,200.00） | −1,200.00 |
| 加：已输入融资 | 0.00 |
| 年末现金 | **16,954.50** |

因此全年现金只增加4,954.50元，而非净利润20,316元。这是现金与经营损益的简化勾稽，不是完整三张财务报表核平。

## 45元与50元报价：本次采用谁

**主模型采用已确认预算的45元/单。** 2026年11月10日供应商提出50元/单，规格和币种可比，但文件明确“尚未签约，经营者尚未接受”。日期较新不等于预算已获批准变更，因此50元不会覆盖45元。乐观44.10元和保守48.60元来自预算已给定的成本倍率，不能把这些值写成已签供应商价格。[来源：供应商补充](../inputs/supplier-proposal.md)；[来源：已确认预算](../inputs/confirmed-budget.json)。

为了让报价决策有依据，另算“如果基础成本50元从2027年1月起生效”的影响。它是假设敏感性，实际是否接受、何时生效仍待经营者决定；除基础成本外，每种情景的其他参数保持不变：

| 情景 | 假设50元时净利润 | 较主预测净利润变动 | 假设50元时年末现金 | 最少补充资金 | 较主预测多需资金 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 基准 | 11,232.00 | -9,084.00 | 7,870.50 | 3,437.50 | 1,300.00 |
| 乐观 | 32,707.28 | -10,556.56 | 27,352.49 | 1,914.36 | 1,430.80 |
| 保守 | -16,573.80 | -9,498.44 | -18,005.61 | 18,005.61 | 9,303.82 |

基准全年卖出2,271单。每单成本上涨5元，全年税前成本增加11,355元；在当前月度计税规则下，净利润减少9,084元至11,232元，最低现金从−2,137.50元变为−3,437.50元。因此，这个报价会同时压低盈利并扩大前期资金需求，但上述影响测算不代表已接受提议。

## 需要决定的事和模型边界

1. **先安排2月付款前的现金来源。** 基准月末至少需2,137.50元；若按保守情景准备覆盖全年的额度，至少需8,701.79元，并另留月内波动及融资费用余量。资金来源、条件和承诺尚未给出，主预测仍保持融资0。
2. **决定供应商报价是否接受及生效月份。** 接受后再更新实际生效月份的成本，核对付款条款。当前50元敏感性假定整年生效，是为比较影响而设，不能代替合同。
3. **复核2月12,000元设备付款的具体日期。** 目前完全按已确认预算执行；可与设备供应商商谈分期或调整日期，但只有获准后才能改主模型。
4. **用实际经营资料校准销量与回款。** 没有提供历史报表、合同订单或账龄表。销量增长、回款65%、无坏账、无库存变动等沿用预算，尚不能声明符合真实经营。
5. **补齐实际税务与折旧口径。** 20%税率和200元/月折旧是明确模型假设；所得税按正的月度税前利润当月计付，不处理税损结转。未包含增值税、利息或未输入费用，也没有自动用设备采购推算新增折旧。[来源：预算假设与包内计算规则](../method/references/operating-forecast.md)。

本任务不含DCF或企业估值。没有完整资产负债表，不声称资产负债已核平；没有进行真实业务验收或方法专业效果评测。

## 文件与复算

- `forecast.json`：schemaVersion为1，三个情景各12个月，包含收入、净利润、回款、付款、融资、期末现金，以及月度成本、税、应收应付和汇总；另附明确标记的报价敏感性。
