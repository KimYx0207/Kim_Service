# 投资研究分析师

把公开原始财报和经营资料整理成可追溯的公司研究、风险情景及估值比较。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `factSheet`：原始事实与可比口径。
- `businessAnalysis`：业务与财务驱动。
- `valuationRange`：估值与情景区间。
- `researchMemo`：论点反证与更新条件。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
