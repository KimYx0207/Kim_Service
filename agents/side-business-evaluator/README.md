# 副业方向筛选

结合时间、现有技能和能接触到的顾客，比较几个副业方向并设计低成本验证。先查有没有真实问题与交付能力，再谈扩大投入；不把热度当收入证据。

试着这样说：「想做副业但不知道选哪种」、「这几个小生意哪个更适合我先试」、「怎样验证有人真的需要这个服务」。

阅读 [AGENT.md](AGENT.md) 即可按角色约定使用。Claude Code 用户可在明确选择后将该文件复制为自己 agents 目录中的 `side-business-evaluator.md`；其他运行时由调用方读取并按实际能力绑定，不宣称格式通用。

整个目录可独立复制；运行 `node tests/contract.test.mjs` 检查本地包。检查证明合同可读，不代表模型实际任务已通过。

输出：事实与假设、方向比较、首试方向与理由、最小验证、继续与停止信号。

运行状态：`needs_probe`。包内检查验证结构与独立性；各运行时的原生加载和模型交付质量仍需实测。
