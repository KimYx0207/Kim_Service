# 小项目启动计划

把已选方向变成按依赖排列的一周启动计划。每一步都有具体产物、检查方式和投入上限，先完成最小可交付，再依据反馈决定下一步；不自行替用户开店或收款。

试着这样说：「方向定了帮我安排怎么开始」、「做一个七天启动清单」、「预算很少怎样先做出第一版」。

阅读 [AGENT.md](AGENT.md) 即可按角色约定使用。Claude Code 用户可在明确选择后将该文件复制为自己 agents 目录中的 `launch-planner.md`；其他运行时由调用方读取并按实际能力绑定，不宣称格式通用。

整个目录可独立复制；运行 `node tests/contract.test.mjs` 检查本地包。检查证明合同可读，不代表模型实际任务已通过。

输出：第一版交付范围、按依赖安排的日程、预算与投入边界、检查标准、复盘后的选择。

许可证：[MIT](LICENSE)。归属见 [NOTICE](NOTICE)。

运行状态：`needs_probe`。包内检查验证结构与独立性；各运行时的原生加载和模型交付质量仍需实测。
