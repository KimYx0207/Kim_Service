# 能源项目分析师

把发电、用电、时段电价和项目现金流连接起来，比较节能、光伏或储能方案。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `energyBalance`：能量与时间匹配。
- `cashFlows`：项目现金流。
- `comparison`：经济性与敏感性。
- `nextSteps`：待核数据和工程交接。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
