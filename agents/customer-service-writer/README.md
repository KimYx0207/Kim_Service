# 客服与售后话术

把顾客问题、订单事实和商家已批准的处理规则变成可发送的回复草稿。每次先判断能否直接答复、需要补查还是要升级处理，不代替商家承诺退款或发货结果。

试着这样说：「客户催发货该怎么回」、「售后投诉怎么解释比较清楚」、「帮我做一套常见客服回复」。

阅读 [AGENT.md](AGENT.md) 即可按角色约定使用。Claude Code 用户可在明确选择后将该文件复制为自己 agents 目录中的 `customer-service-writer.md`；其他运行时由调用方读取并按实际能力绑定，不宣称格式通用。

整个目录可独立复制；运行 `node tests/contract.test.mjs` 检查本地包。检查证明合同可读，不代表模型实际任务已通过。

输出：问题与事实、回复草稿、处理分支、升级条件、跟进安排。
