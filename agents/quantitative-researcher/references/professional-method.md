# 定量研究与可复算分析：专业方法

知识修订：0.2.0，2026-11-10。本文是本包原创方法与合成算例，不是第三方包副本。

## 输入与适用范围

- 给定数据的研究设计、计算和局限
- 研究辅助；不执行交易或保证收益

- `hypothesis`：明确比较对象、指标和可能反证。 缺失时：先缩小待研究的问题。
- `dataset`：样本、单位、时间字段和缺失规则。 缺失时：只交研究设计与数据缺口，不伪造行情。
- `method`：切分、计算、成本、选择规则及基准。 缺失时：给可选方法及其假设，关键定义未定前不作效果结论。

完整输入/输出仍以同包 capability.json 为准；acceptanceCriteria/handoffContext 若由合同要求，应采用当前任务绑定，不能把材料当授权。

## 领域知识

- 先定义观察单位、目标量、样本选择和可用时间。交易信号要早于执行；按今天仍存续的对象回填历史样本会改变研究总体。未记录缺失、退市或数据修订，漂亮曲线也可能回答了另一个问题。
- 训练、参数选择与最终评价各有边界。预处理仅在训练部分拟合；时间相关资料按可获得时间切分。若在测试集反复挑最优参数，它就参与了选择，不能继续称为独立检验。
- 净值按明确收益/费用定义逐期相乘，不将均值收益直接当复利收益。最大回撤比较每个时点净值与此前峰值；年化需说明周期与假设。短样本、合成序列和忽略交易可行性的算例只能验证算术，不能证明策略有效。

## 诊断顺序

### estimand：研究要比较哪一个量，样本代表谁？

检查：假设、观察单位与基准；缺失/退出对象和样本期间。缺证据时：先给数据需求与可计算范围，不替缺失价格或费用填零。

### time-order：模型/策略在当时能看到哪些信息？

检查：每字段可用时间；训练、选择、检验与执行时点。缺证据时：未证明时序时暂停策略效果结论，仍可交数据审查结果。

### robustness：结论是否依赖少量参数或单一情景？

检查：费用与执行条件；样本外/敏感性结果和复算输入。缺证据时：把稳健性列未验证；不要把单点最佳当一般规律。

## 决策方法

- **separate-fit**：要进行预处理、特征筛选或调参时，先分离评价样本，再仅在训练数据拟合；记录每次选择。拒绝：在全量数据标准化后宣称样本外有效。
- **state-costs**：已有收益但成本、现金流或成交规则不明时，明确按哪种公式计算；输出条件结果与不能推断的结论。拒绝：将未知成本默认为零或将模拟收益解释成可实现收益。
- **replicate**：算式和输入完整时，用现有计算 helper 或独立算式复算，保留输入版本/参数/实际输出。拒绝：把写了计算步骤、代码可导入或自报 pass 当真实运行。

## 交付与验收

- `research`：问题、样本与信息时序一致，区分探索和检验。 不通过情形：把事后调参结果称为独立检验。
- `results`：计算有单位、期间、成本和适用范围。 不通过情形：少量合成数据推出稳定收益或省略负面情景。
- `reproducibility`：绑定数据版本、参数、公式和实际运行/未运行状态。 不通过情形：把 helper 存在当已运行或用未知随机状态宣称可复现。

## 工具与实际执行

保留本包已有 calculation-tool.json 与 calculate helper。宿主明确绑定后才能称实际调用；无绑定可展示可复算公式并注明未执行。数据与运行版本须来自真实环境，不为补资料安装新交易工具或访问账户。

## 正例与反例

以下是作者设计的合成片段，不是模型运行记录，也不是完整正式交付；预期判断仍需独立专业复核。

### compound-check（可接受候选）

三期合成收益1%、-2%、3%，每期在同一乘数内扣0.1%，起始净值1。

输入：{"hypothesis":"比较固定持有与带成本日调仓","dataset":"合成三个周期收益，非真实行情","method":"初始净值1；收益1%、-2%、3%；单期扣费0.1%"}

候选输出片段：

```json
{
  "results": "净值为 1.009 × 0.979 × 1.029 = 1.016457519；该收费定义下最大回撤2.1%。只是合成算术例，未证明真实策略收益。"
}
```

判断理由：费用规则与复利公式明确，结论限于给定序列。

### leaked-transform（应拒绝候选）

先用全样本拟合标准化器，再按时间切分评价。

输入：{"hypothesis":"评价未来样本上的分类表现","dataset":"合成时间序列；标准化器拟合时已经看到最后一个月","method":"在最后一个月报告独立测试精度"}

候选输出片段：

```json
{
  "research": "最后一个月完全独立，测试精度可直接代表未来表现。"
}
```

判断理由：拟合已使用测试期信息，必须更正流程并重新评价。

## 失败与人工边界

- 投资、信贷、税务或其他金融决策须由具备资格的人复核；研究计算不构成个人交易建议。
- 高影响统计推断需要相应领域审查与适用的数据授权。
- 必要事实/能力缺失时交具体影响和下一步，不伪造执行；只停止受影响部分，整体调度由调用方决定。
- 专业效果状态是 `not_evaluated`；合同验证和资料完整字节交接只证明结构与来源运输，不能代替真实任务质量。
