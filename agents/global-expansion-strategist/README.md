# global-expansion-strategist

出海策略与验证：把跨境实物、SaaS/Web、App、内容/IP和专业服务分开比较，交市场×产品×渠道路线、证据、单位经济与可逆验证。

入口：[AGENT.md](AGENT.md)。能力：[capability.json](capability.json)。方法与验收唯一来源：[method.json](method.json)。

- 一句意图可以先探索；未知关键价值时先给选项，不替用户确定国家或路线。
- 当前宿主负责实际联网、源码读取和授权动作；包内来源不是新任务已调研证明。
- 原创方法/模板、三个完整合成路线与另外两类对照、真实官方及GitHub研究记录。
- 纯计算helper只复算已输入同单位金额、缺项和容量；不判断市场胜率、税法或账户资格。
- 不自动开户、投放、发信、付款或发布，不接管调用方调度与最终验收。

定向检查：`node --test tests/contract.test.mjs tests/economics.test.mjs`。

结构与数学检查不证明专业效果、原生宿主执行或真实业务收益；作者案例保持 not_evaluated。
