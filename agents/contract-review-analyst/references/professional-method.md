# 商业合同条款分析师：专业方法

将冗长商业合同及附件拆解为“原文事实定位”与“交易风险推演”严格分离的条款矩阵，识别跨条款隐蔽耦合陷阱，输出可直接用于商务拉锯的分级谈判方案与履约义务日历。

## 1. 原文提取与风险评价两段式隔离

审阅合同时最忌讳把推测当成合同明文，或因上下文漏读把“未检索到”写成“合同未限制”：
- **最小可核查提取单元**：每条记录必须指明 `文档名称与版本 + 条款编号/页码 + 义务主体 + 触发条件 + 核心行为/金额/期限 + 例外排除（Carve-outs）+ 关联大写/专有定义项`。
- **材料完整性声明**：扫描件模糊页、未提供的附件（如《服务级别协议 SLA》《信息安全附件》《报价单》）或外部超链接引用的线上政策，必须单列为**材料盲区（Document Gap）**；在可读文本中未见某约定，只能表述为“当前所供文本范围内未见约定”，不能断言整套交易不存在该义务。

## 2. 六大高危跨条款耦合链核查表

真正引发重大商业损失的往往不是单句霸王条款，而是分散在不同章节的两三条约定组合发力：

| 耦合链主题 | 需交叉比对的条款位置 | 典型隐蔽陷阱 | 谈判修正要点 |
|---|---|---|---|
| **1. 验收卡点 × 付款挂钩** | 交付验收章 + 付款里程碑章 + 违约金章 | 约定“经甲方书面终验合格后付尾款”，却无明确验收客观标准与逾期不回复视为默示通过期限（Deemed Acceptance） | 绑定可量化验收清单 + 明确提交后 `N` 个工作日内未提出书面实质缺陷即视为验收通过 |
| **2. 责任上限 × 例外穿透（Super-Cap / Uncapped）** | 责任限制章 + 赔偿（Indemnity）+ 保密/数据安全章 | 正文写了“累计赔偿上限不超过合同总额 100%”，但紧接着把违约、数据、知识产权、间接损失全部排除在上限之外，导致上限形同虚设 | 区分一般违约上限、数据/IP 增强上限（Super-Cap，如 `2x~3x` 年度费用）与法定不可免责底线，收窄无限责任敞口 |
| **3. 背景知识产权 × 定制成果归属** | 定义章 + 知识产权归属章 + 许可范围章 | 约定“本项目产生的一切成果及包含物全部归客户独占所有”，把乙方既有底层框架、通用工具库与方法论一并锁死，禁止服务同行 | 拆清**既有背景知识产权（Background IP，归原权利人，授客户伴随使用许可）**与**专项定制前景成果（Foreground Deliverables）** |
| **4. 变更范围 × 固定总价锁死** | 服务范围（SOW）+ 变更管理章 + 单方指令权 | 固定总价合同中赋予一方“根据业务需要合理调整需求”且未约定工时/费用重议门槛 | 明确基准范围外的新增需求须经双方书面变更单（Change Order）确认排期与增补费用后方生效 |
| **5. 自动续约 × 严苛退出窗口** | 合同期限章 + 提前终止章 + 通知送达章 | 每年自动续期且涨价上限不明，仅允许在到期前 `60~90` 天以特定挂号信/专函通知不续约，错过一天即锁死下一年全款 | 缩短不续约通知窗口或改为双方书面确认续签；对齐电子邮件等日常有效送达方式 |
| **6. 终止交接 × 数据留存销毁** | 违约解除章 + 退出过渡期服务 + 保密留存例外 | 合同解除即刻断服且不退预付款，或要求“立即彻底删除一切副本”却与法定审计/合规归档留存义务冲突 | 明确按已履行合格部分结算退费、过渡期数据导出格式，以及合规备份隔离留存例外（保密义务持续有效） |

## 3. 三档谈判红线设计法（Three-Tier Playbook）

吸收 CUAD 按条款类别锚定原文证据片段的结构化审查思路（不导入外部数据集，更不将英美判例默认套用于中国法或其他准据法域），每项核心修改建议按三档交付：
1. **首选方案（Preferred Position）**：清晰保护己方核心利益且商业理由充分的替代条文草案，说清对双方的公平合理性。
2. **可接受退让底线（Acceptable Fallback）**：当对方拒绝首选方案时，可通过缩窄触发条件、设置分档金额上限、缩短持续期限或对等互惠（Mutual）换取成交的折中写法。
3. **升级审批红线（Escalation / Walk-Away Trigger）**：触及无上限连带赔偿、核心自有 IP 丧失、单方无限期压款或违法合规风险时，标记必须提交法务负责人与业务管理层签字决策。

修改任何条款拟文后，必须反向回查**定义章节与跨条款编号引用**，防止改了第 8 条却让第 14 条引用失效或无意删掉己方保护伞。本包仅交付商务与文本审查草案，不替代执业律师正式法律意见书，也不自动对外发送或签署合同。
