# 商业合同条款分析师：合成交付演练

所有数值、条款、设备、账户和业务对象均为合成教学材料；预期判断尚未经过真实行业任务评测。

## 输入

```json
{
  "contract": {
    "version": "合成v1",
    "clause8": "一般责任上限=过去12个月已付费用",
    "clause8_3": "保密与知识产权赔偿不受8条上限约束",
    "clause12": "每年自动续约，期满前30自然日按约定邮箱送达通知"
  },
  "context": {
    "role": "服务采购方",
    "jurisdiction": "未提供"
  },
  "playbook": "需要明确最大责任与退出窗口"
}
```

## 分析与可复核结果

合成合同第8条：一般责任上限为过去12个月已付费用；第8.3条例外列保密和知识产权赔偿。第12条：每年自动续约，终止通知须在期满前30个自然日按约定邮箱送达。
正确交付：责任上限仅覆盖一般责任，保密/IP赔偿另核；续约日需由当前合同期确定，不按发票日推算。建议可为例外设置独立上限、限定间接损失，并对通知增加送达确认机制。没有法域时不判断条款必然无效。

## 当前交付字段

- `clauseMatrix`：合成v1第8条给一般责任上限=过去12个月已付费用；8.3条保密/IP赔偿不受该上限；12条期满前30自然日约定邮箱通知，否则逐年续约。完整附件优先顺序未给。
- `riskAnalysis`：全部责任封顶说法与8.3矛盾；须另核例外责任规模与可承保性。未给适用法域，法律效力及违约救济交当地专业审核。
- `negotiationOptions`：方案A为保密/IP例外约定独立上限并定义可赔损失，换取清楚的通知与补救义务；方案B保留例外但收窄触发范围、排除非己方原因。金额、对价和接受程度未给，只交谈判草案。
- `obligationCalendar`：终止通知相对期满日T为T−30自然日，需核实际合同期满日、通知邮箱及送达证明；目前不能生成真实日历日期。
- `facts`：本例所有对象和数值为合成，来源是本页input对应字段；未提供的真实文档、观察日或外部事实均不补造。各已给单位、日期和条款版本按原字段保留。
- `limitations`：仅完成所示条件推导与文本分析；未连接实际业务系统、未验证真实来源，未执行外部变更。缺口及其影响已经分布到各领域输出。
- `handoff`：本页作为合成交付示范；实际任务按delivery-template和method.json交同名字段、原材料位置与逐项检查证据。将上述待核材料交当前调用方继续，不创建新的授权或业务状态。

以上覆盖当前合同全部必填字段；它是合成输入的完整交付演练，不是实际业务验收。
