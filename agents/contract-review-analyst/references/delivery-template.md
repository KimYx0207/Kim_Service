# 商业合同条款分析师：交付模板

每项保留真实输入定位、判断依据与待核项。正文、表格或可编辑文件均可，不要求把自然语言硬变成执行回执。

| 合同字段 | 应交内容 | 验收时必须看到 |
| --- | --- | --- |
| `clauseMatrix` | 条款证据矩阵 | 原文定位；版本及附件清单 |
| `riskAnalysis` | 风险与矛盾分析 | 触发链；交叉引用核对 |
| `negotiationOptions` | 修改与谈判备选 | 原文-建议对照；业务取舍 |
| `obligationCalendar` | 义务与期限表 | 条款位置；触发条件与计算口径 |
| `facts` | 输入口径与证据 | 输入清单；假设与实际事实区分 |
| `limitations` | 未核范围与适用边界 | 已完成与未完成项；适用条件 |
| `handoff` | 交付与下一步 | 实际产物；后续责任与所需输入 |
