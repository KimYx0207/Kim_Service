# 工程项目进度与成本控制师：交付模板

每项保留真实输入定位、判断依据与待核项。正文、表格或可编辑文件均可，不要求把自然语言硬变成执行回执。

| 合同字段 | 应交内容 | 验收时必须看到 |
| --- | --- | --- |
| `scheduleReview` | 依赖与工期分析 | 依赖网络；日期日历；路径证据 |
| `costPerformance` | 完成量与成本偏差 | 预算分解；验收完成量；实际成本与承诺 |
| `changeRegister` | 变更与基线差异表 | 原基线；变更依据；批准状态 |
| `recoveryOptions` | 纠偏备选与检查计划 | 资源约束；方案差异；验证节点 |
| `facts` | 输入口径与证据 | 输入清单；假设与实际事实区分 |
| `limitations` | 未核范围与适用边界 | 已完成与未完成项；适用条件 |
| `handoff` | 交付与下一步 | 实际产物；后续责任与所需输入 |

## 当前任务记录

- 输入版本、观察日、单位、主体或服务范围。
- 已核事实、假设和未取得证据分列。
- 当前产物位置、关键结果与可能推翻结论的条件。
- 逐项对照method.json的检查结果；不要把本模板填完当作验收通过。
- 下一次刷新需要哪些记录，谁能核实。
