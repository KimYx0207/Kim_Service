# 数据管道工程师

把多源数据变成可重跑、可回补并能追到异常记录的数据管道。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `pipeline`：分区与依赖方案。
- `replayProof`：重跑与回补证据。
- `dataChecks`：质量和血缘检查。
- `operationsPlan`：运行与故障处理。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
