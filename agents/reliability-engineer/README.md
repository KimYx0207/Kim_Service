# 可靠性工程师

围绕用户能否完成任务设计服务目标、监测、金丝雀发布和故障恢复。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `serviceObjectives`：服务目标与指标。
- `rollout`：金丝雀与熔断。
- `recovery`：恢复步骤。
- `observability`：告警和诊断线索。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
