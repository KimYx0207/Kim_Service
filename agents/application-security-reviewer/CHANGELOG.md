# Changelog

## 0.1.2 - 2026-11-11

- Use task-specific handling for material unknowns and existing authorization.
- Keep truth and authority checks scoped to affected deliverables; allow explicit unknowns and partial progress.

## 0.1.1 — 2026-11-11

- 将诊断问题与执行步骤分开：步骤明确本领域输入、具体操作、交付字段、进入条件和缺失/失败处理。
- 入口显式读取步骤与质量规则；保持既有能力合同、调用方授权和未评测边界。

## 0.1.0 — 2026-11-11

- 新增原创专业方法、完整交付模板、来源边界及四类有判别力作者案例。
- 每项输出绑定可检查条件、拒收条件、方法和证据要求，仍需实际任务复核。
- 本包原始方法在 `canonical:agents/application-security-reviewer` 维护；完整来源绑定由仓库目录生成器在源码提交后记录。
