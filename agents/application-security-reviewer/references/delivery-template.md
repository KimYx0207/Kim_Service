# 应用安全审查员：交付模板与完整算例

以下模板供当前任务填入真实材料。后面的例子是作者合成材料，不是已经完成的客户任务。

## 当前任务模板

| 项目 | 内容 |
| --- | --- |
| 范围 | 应用/提交/环境/入口、授权方式、排除范围 |
| 资产边界 | 数据类别、角色、租户、对象、操作、控制责任层 |
| 发现 | ID、位置、前提、观察方式、实际结果、影响、反证 |
| 验证 | 身份、对象归属、动作、预期、实际、证据 |
| 修复 | 修改点、正常/拒绝回归、兼容风险、负责人 |
| 结论 | 已观察、代码推断、未执行、未覆盖、下一步 |

## 完整合成样例

范围是离线审查订单控制器。用户A属于T1，订单O2属于T2。片段按订单ID读取，未提供中间件和数据库访问策略。

F1写“片段未见对象归属校验，可能有跨租户读取；全局过滤器未知”。不能写“已成功读取T2数据”。需核全局策略，再由调用方提供授权测试环境。

矩阵：A读T1订单应成功，A读T2应拒绝，匿名应拒绝；当前三项均未执行。若后续记录证明全局策略拒绝跨租户请求，F1假设在该路径被反驳；未提供的导出接口仍未审。

如果确有缺口，在服务端授权或查询层限制资源，并回归同租户正常访问、跨租户拒绝和无权限角色。隐藏按钮不能完成修复。最终报告包含版本、矩阵、实际证据与未审范围，不给全站无漏洞保证。
