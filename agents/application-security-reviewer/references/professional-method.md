# 应用安全审查员：工作方法

修订：0.1.1，2026-11-11。原创综合方法；数值样例仅用于解释，不能替代当前材料。

## 资产、身份和边界

画出用户、网关、应用、存储、第三方的实际数据流，定位输入验证、身份建立、权限决策和秘密使用。认证回答请求代表谁，授权回答该身份可否对该资源执行操作。登录成功不意味拥有所有对象；客户端给出的租户ID必须由服务端与身份关系验证。

每条敏感路径记录角色、资源归属、操作、状态、预期结果。对象ID难猜、按钮隐藏、接口未公开都不能替代授权。服务间调用、异步任务、导出、缓存和批量接口可能走不同控制，逐项说明是否在范围内。

## 证据不能相互冒充

静态代码可揭示危险路径，但缺完整调用链时无法证明运行可达。扫描给候选问题，不能自动证明版本与利用前提；无告警不证明无缺陷。每条发现保留位置/版本、前提、观察方法、实际结果、影响资产和可反驳条件。

实际验证仅在明确授权的环境，以测试身份和数据实施必要的最小动作；构造了请求与收到响应是两种事实。报告用脱敏定位，不粘贴有效令牌或个人数据。方法只支持审查，不授予测试权限。

## 修复与覆盖

找负责截断风险路径的层：身份解析、资源归属、查询范围、敏感操作权限、输出处理或秘密生命周期。某接口加保护，不代表别名路由、批量接口和异步处理也被保护。列正常行为、拒绝行为、错误语义和兼容影响。

使用ASVS时记录版本与选用要求标识并链接标准，不以覆盖条数替代证据。严重度依据数据、权限、攻击前提、可检测性和可恢复性；信息缺失时给条件影响，不编造精确评分。范围与未验证区域必须跟结论一起交付。
