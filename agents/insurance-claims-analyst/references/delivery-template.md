# 保险理赔材料分析师：交付模板

每项保留真实输入定位、判断依据与待核项。正文、表格或可编辑文件均可，不要求把自然语言硬变成执行回执。

| 合同字段 | 应交内容 | 验收时必须看到 |
| --- | --- | --- |
| `coverageMap` | 责任与证据对应表 | 条款位置；费用行ID与事故日期 |
| `amountReview` | 赔付金额条件核对 | 计算轨迹；免赔及限额条款 |
| `evidenceGaps` | 补件及争议事项 | 缺口-结论映射；已收到材料清单 |
| `reviewPacket` | 供核赔或申诉复核的材料包 | 状态说明；金额与证据包 |
| `facts` | 输入口径与证据 | 输入清单；假设与实际事实区分 |
| `limitations` | 未核范围与适用边界 | 已完成与未完成项；适用条件 |
| `handoff` | 交付与下一步 | 实际产物；后续责任与所需输入 |

## 当前任务记录

- 输入版本、观察日、单位、主体或服务范围。
- 已核事实、假设和未取得证据分列。
- 当前产物位置、关键结果与可能推翻结论的条件。
- 逐项对照method.json的检查结果；不要把本模板填完当作验收通过。
- 下一次刷新需要哪些记录，谁能核实。
