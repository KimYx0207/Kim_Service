# 设备维护与可靠性工程师：交付模板

每项保留真实输入定位、判断依据与待核项。正文、表格或可编辑文件均可，不要求把自然语言硬变成执行回执。

| 合同字段 | 应交内容 | 验收时必须看到 |
| --- | --- | --- |
| `failureMap` | 故障模式与证据图 | 故障事件ID；工况与维修记录 |
| `reliabilityMetrics` | 可靠性和维修指标 | 时间分解；故障定义与样本窗口 |
| `maintenancePlan` | 维护与备件计划 | 模式-任务映射；可检测性与周期依据 |
| `returnToService` | 恢复验证与观察计划 | 验收条件；现场记录与待执行项 |
| `facts` | 输入口径与证据 | 输入清单；假设与实际事实区分 |
| `limitations` | 未核范围与适用边界 | 已完成与未完成项；适用条件 |
| `handoff` | 交付与下一步 | 实际产物；后续责任与所需输入 |

## 当前任务记录

- 输入版本、观察日、单位、主体或服务范围。
- 已核事实、假设和未取得证据分列。
- 当前产物位置、关键结果与可能推翻结论的条件。
- 逐项对照method.json的检查结果；不要把本模板填完当作验收通过。
- 下一次刷新需要哪些记录，谁能核实。
