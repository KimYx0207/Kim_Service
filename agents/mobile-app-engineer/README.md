# 移动应用工程师

把一个移动端用户流程做成可实现的页面、状态与同步方案，重点处理离线、重启和重复提交。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `implementation`：页面与本地状态实现方案。
- `syncProtocol`：离线队列与同步协议。
- `deviceChecks`：设备行为验收。
- `handoffPlan`：联调与发布交接。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
