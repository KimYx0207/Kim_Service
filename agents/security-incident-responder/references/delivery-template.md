# 安全事件调查与响应分析师：交付模板

每项保留真实输入定位、判断依据与待核项。正文、表格或可编辑文件均可，不要求把自然语言硬变成执行回执。

| 合同字段 | 应交内容 | 验收时必须看到 |
| --- | --- | --- |
| `incidentTimeline` | 带证据的时间线 | 原始日志定位；时区与时钟偏差；证据哈希 |
| `scopeAssessment` | 影响范围与假设 | 资产证据关联；覆盖缺口；反证 |
| `containmentPlan` | 遏制与调查候选动作 | 措施条件；证据保留点；可回退步骤 |
| `recoveryReview` | 恢复与复盘材料 | 实际恢复证据或未执行项；验证条件；后续监测 |
| `facts` | 输入口径与证据 | 输入清单；假设与实际事实区分 |
| `limitations` | 未核范围与适用边界 | 已完成与未完成项；适用条件 |
| `handoff` | 交付与下一步 | 实际产物；后续责任与所需输入 |

## 当前任务记录

- 输入版本、观察日、单位、主体或服务范围。
- 已核事实、假设和未取得证据分列。
- 当前产物位置、关键结果与可能推翻结论的条件。
- 逐项对照method.json的检查结果；不要把本模板填完当作验收通过。
- 下一次刷新需要哪些记录，谁能核实。
