# 安全事件调查与响应分析师：合成交付演练

所有数值、条款、设备、账户和业务对象均为合成教学材料；预期判断尚未经过真实行业任务评测。

## 输入

```json
{
  "incident": {
    "id": "SYN-1",
    "authorizedAssets": [
      "A",
      "B"
    ],
    "timezone": "UTC",
    "businessImpact": "待核"
  },
  "evidence": [
    {
      "id": "E1",
      "asset": "A",
      "eventTime": "09:00Z",
      "collectedTime": "09:10Z",
      "fact": "未知程序执行",
      "clock": "已核同步"
    },
    {
      "id": "E2",
      "asset": "B",
      "eventTime": "09:02Z",
      "collectedTime": "09:05Z",
      "fact": "同账号成功登录",
      "clock": "已核同步"
    }
  ],
  "responseContext": "仅只读分析，尚未执行隔离或会话撤销"
}
```

## 分析与可复核结果

合成告警：主机A的进程日志记09:00 UTC执行未知程序；身份日志09:02 UTC记录同账号成功登录主机B；日志采集分别在09:10和09:05。时钟均已核同步。时间线应以09:00、09:02为事件时间，保留两个采集时间。
此时可确认A有执行记录、B有登录记录，但不能仅凭同账号断言B已执行恶意载荷。候选措施是保全A相关日志和进程证据、核B登录来源及后续活动，按现有权限决定会话撤销或资产隔离。未做现场操作，不称已遏制。

## 当前交付字段

- `incidentTimeline`：SYN-1：E1/A于09:00Z未知程序执行，09:10Z采集；E2/B于09:02Z同账号登录，09:05Z采集；题设时钟已同步。证据文件哈希未给，不能称字节保全已校验。
- `scopeAssessment`：A执行和B登录为已观察事实；账号关联不能证明B恶意执行或A到B横向移动。业务影响、更多资产及日志覆盖仍未知。
- `containmentPlan`：先在既有授权范围保全E1/E2原日志及采集元数据，核B来源、会话与后续活动；隔离/撤销会话需业务依赖和权限，未执行任何生产变更。
- `recoveryReview`：没有实际遏制、根因修复或恢复验证证据，状态为未观察。后续需核账号权限、受影响功能、安全控制与持续异常；不能因无新告警宣称清除完成。
- `facts`：本例所有对象和数值为合成，来源是本页input对应字段；未提供的真实文档、观察日或外部事实均不补造。各已给单位、日期和条款版本按原字段保留。
- `limitations`：仅完成所示条件推导与文本分析；未连接实际业务系统、未验证真实来源，未执行外部变更。缺口及其影响已经分布到各领域输出。
- `handoff`：本页作为合成交付示范；实际任务按delivery-template和method.json交同名字段、原材料位置与逐项检查证据。将上述待核材料交当前调用方继续，不创建新的授权或业务状态。

以上覆盖当前合同全部必填字段；它是合成输入的完整交付演练，不是实际业务验收。

## 看起来完整但应拒收

```json
{
  "scopeAssessment": "采集09:05早于09:10，证明B先攻陷A；两台均已清除威胁。"
}
```

混用采集与发生时间，编造因果、影响范围与恢复完成状态。

## 材料不全时仍能交什么

- `scopeAssessment`：情报命中仅作线索；列需核的连接、进程和身份日志，不能认定入侵或归因攻击者。
