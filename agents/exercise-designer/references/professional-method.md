# 练习设计与答案核验：专业方法

知识修订：0.2.0，2026-11-10。本文是本包原创方法与合成算例，不是第三方包副本。

## 输入与适用范围

- 按具体学习目标编写题目和完整答案
- 检查题目是否测到目标；不自称心理测量学验证

- `learningTarget`：当前要观察的知识/技能和学习阶段。 缺失时：先确定目标，不无依据设难度和题量。

完整输入/输出仍以同包 capability.json 为准；acceptanceCriteria/handoffContext 若由合同要求，应采用当前任务绑定，不能把材料当授权。

## 领域知识

- 每道题先决定要观察哪一种理解，再写题面和答案。需要概念辨别时不能全是机械计算；想检查程序步骤时也不要用复杂阅读包装引入无关难度。题量和难度由目标与限制决定，不为凑固定比例填题。
- 题干条件、单位、图示和所指整体必须足以得到预期答案。选择题的错误项应对应具体误解，不是明显荒谬选项；多个合理答案要接受或修订题目，不能用答案钥匙否定题面允许的解法。
- 独立重做每题，再从错误解释、等价表达和评分条件逆查题干。评分区分目标错误与尚未教的附加要求；例如未要求约分时，不能仅因等价分数未约分判概念错误。练习题经过作者复算仍不等于经真实学生试测。

## 诊断顺序

### construct：每题要测哪一个目标，而非什么表面形式？

检查：学习目标与已学知识；目标—题型覆盖蓝图。缺证据时：先给小范围蓝图，不任意增加未学内容。

### ambiguity：条件和单位是否足够，有无多解？

检查：题干、图示与完整解题过程；等价答案/隐含假设。缺证据时：补条件或接受多解，不把缺条件转嫁给学生。

### error-model：典型错答反映什么误解，如何评分？

检查：常见错误步骤；评分规则与可接受表达。缺证据时：把错因作为待观察假设，不从单题作能力诊断。

## 决策方法

- **align-items**：题目主要考了非目标能力时，简化语言/计算负担或换题，确保目标可观察。拒绝：用复杂题面制造难度后称更专业。
- **accept-equivalence**：答案表达不同但满足题意时，按目标接受等价解法，说明附加约束是否存在。拒绝：把未约分或另一合法方法一律判错。
- **verify-key**：准备交付答案钥匙时，独立复算并用反例/边界逆查题干。拒绝：只生成题目不核答案，或按模板自动判定唯一解。

## 交付与验收

- `blueprint`：题目与目标、难点和作答证据对应。 不通过情形：只有题型数量没有测量意图。
- `questions`：条件、单位与图示清楚，阅读负担适合目标。 不通过情形：存在未说明的多解或引入未学概念。
- `answerKey`：完整可核答案、必要过程和等价表达。 不通过情形：答案与题意矛盾或把所有等价形式排除。
- `errorChecks`：对应具体误区和可用反馈。 不通过情形：用笼统不认真替代诊断。
- `adaptations`：按真实需要调整支架或挑战，保持目标。 不通过情形：无证据声称已验证难度、区分度或适合所有学生。

## 工具与实际执行

用手工或宿主允许的计算工具独立复算。图题必须实际检查图与题文一致；没有渲染时标明图示待核。保留已有同分母分数示例，不把合同测试当真实学生试测。

## 正例与反例

以下是作者设计的合成片段，不是模型运行记录，也不是完整正式交付；预期判断仍需独立专业复核。

### equivalent-answer（可接受候选）

学生尚未学约分，目标为同分母分数相加。

输入：{"learningTarget":"同分母分数相加，尚未教学约分","constraints":"答案可保留同分母形式"}

候选输出片段：

```json
{
  "questions": [
    "2/8 + 2/8 = ?"
  ],
  "answerKey": [
    "4/8；1/2是等价答案，也接受。"
  ],
  "errorChecks": [
    "若答4/16，检查是否误把分母也相加；未约分不作为本题目标错误。"
  ]
}
```

判断理由：题目与目标一致，评分不引入未教要求。

### ambiguous-whole（应拒绝候选）

题目把两块大小不同的饼各自一半直接相加，却不说明参考整体。

输入：{"learningTarget":"理解分数依赖整体","questionPlan":"一大饼的一半加一小饼的一半，共有几块完整饼？未给大小。"}

候选输出片段：

```json
{
  "answerKey": [
    "唯一正确答案是1块完整饼，其他都错。"
  ]
}
```

判断理由：不同整体不可直接用同一单位相加，题干不足支持唯一结果。

## 失败与人工边界

- 用于正式评分、考试公平性或特殊教育安排时，由负责教师/测评专业人员复核。
- 不依据单次题目推断学习障碍或心理状况。
- 必要事实/能力缺失时交具体影响和下一步，不伪造执行；只停止受影响部分，整体调度由调用方决定。
- 专业效果状态是 `not_evaluated`；合同验证和资料完整字节交接只证明结构与来源运输，不能代替真实任务质量。
