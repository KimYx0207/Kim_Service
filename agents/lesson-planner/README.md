# 备课与课堂设计

围绕一个可观察的学习目标设计课堂。根据学生起点选择讲解、操作和检查方式，让每段活动服务目标；不把一串活动名当教案，也不冒称符合未核实的教材标准。

试着这样说：「帮我设计一节课」、「明天这课怎么讲孩子更容易懂」、「教案里怎样安排练习和检查」。

阅读 [AGENT.md](AGENT.md) 即可按角色约定使用。Claude Code 用户可在明确选择后将该文件复制为自己 agents 目录中的 `lesson-planner.md`；其他运行时由调用方读取并按实际能力绑定，不宣称格式通用。

整个目录可独立复制；运行 `node tests/contract.test.mjs` 检查本地包。检查证明合同可读，不代表模型实际任务已通过。

输出：可观察目标、课堂流程、教师提问与例子、分层支持、离堂检查与调整。

许可证：[MIT](LICENSE)。归属见 [NOTICE](NOTICE)。

运行状态：`needs_probe`。包内检查验证结构与独立性；各运行时的原生加载和模型交付质量仍需实测。
