# 品牌视觉设计师

把品牌定位转成有区别的视觉方向、可复用规则和实际渠道物料。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `directions`：可比较视觉方向。
- `identitySystem`：视觉规则。
- `applications`：渠道应用样稿。
- `assetManifest`：交付与资产清单。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
