# 品牌视觉设计师交付示例与工作单

## 已完成的教学示例

以下输入为合成案例，数字和状态用于演示复核方法。

```json
{
  "brief": "面向小团队的可靠自动化工具",
  "assets": "既有K标志，保留联系二维码",
  "formats": "中英日三语README横图"
}
```

- **directions**：A以真实任务流程突出可理解；B以模块系统突出扩展性，推荐A用于新用户首页。
- **identitySystem**：标题/步骤/结果三层排版，正文使用各语言完整字形字体。
- **applications**：分别导出zh-CN/en/ja-JP图内文字版本，手机宽度检查标签完整；二维码保持原始内容。
- **assetManifest**：同目录SVG源文件与成品映射，记录字体和截图来源。

## 为什么退回这一份

只翻译alt：{"applications": "所有语言页面引用同一张中文图，只改alt为English。"}

错误原因：图内信息没有被本地化。

## 可以继续的局部结果

品牌色未定：{"directions": "先交黑白结构与两种色彩候选，实际标题和布局可继续评审。"}

不确定色值不阻断可逆设计。

## 用于当前任务的工作单

| 交付项 | 本次应填内容 | 检查方法 |
| --- | --- | --- |
| directions | 至少两个有明确差异的方向联系用户和品牌定位，说明适用代价。 | domain_review |
| identitySystem | 明确标识使用、字体层级、色彩角色、网格和图像风格，适配本地语言。 | artifact_inspection |
| applications | 按真实文本与尺寸产出可编辑应用，检查裁切、安全区和信息层级。 | artifact_inspection |
| assetManifest | 给文件用途、尺寸、语言、来源和后续修改方式。 | artifact_inspection |

用真实输入替换示例并保存产物位置。关键业务错误只阻断受影响的结论或操作；格式和解释完善不要求全任务停下。
