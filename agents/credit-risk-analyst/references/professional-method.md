# 企业信用风险分析师：专业方法

把法律借款主体、债务期限结构、真实经营偿债现金流、抵质押变现顺位与压力情景连接起来，交付证据链闭环的授信分析草案与贷后监测指标。

## 1. 主体穿透与结构性次级识别（Structural Subordination）

企业集团授信最常见的致命误判，是把**合并报表总现金与总利润**直接当成母公司或单一借款子公司可自由支配的偿债资源：
- **法律主体分层建账**：必须先按具体签约借款主体（Legal Borrower）与担保主体逐笔拆解债项（本金、利率、付息频率、到期日、币种、交叉违约 Cross-Default 与控制权变更条款）。
- **现金可及性核查**：控股母公司（HoldCo）若本身无经营资产、仅靠下属经营子公司（OpCo）分红偿债，则子公司层面的外部债权天然优先于母公司债权受偿（结构性次级）。必须单列受限资金（保证金、监管户、质押存单、外汇管制受限境外资金），严禁直接混入可用偿债现金池。
- **三大还款来源严格分列**：第一还款来源（可持续经营自由现金流）、第二还款来源（抵质押物处置或非核心资产变现）、第三还款来源（外部再融资或股东增信）必须独立列示，禁止将同一笔资产既算持续经营产出又算变现回款。

## 2. 从报表利润到可偿债现金桥（EBITDA-to-CADS Bridge）

账面净利润为正的企业同样会资金链断裂违约。所有覆盖倍数必须在**完全一致的起止期间**内通过可复算现金桥推导：

$$\text{可供债务服务现金（CADS）} = \text{经营性 EBITDA} - \text{现金所得税} - \text{维持性资本开支（Maintenance CapEx）} - \Delta\text{营运资本占用} - \text{不可自由调拨受限现金变动}$$

$$\text{期间债务服务覆盖率（DSCR）} = \frac{\text{当期 CADS}}{\text{当期刚性应付利息} + \text{当期到期应还本金（含租赁本金偿付）}}$$

- **口径与边界约束**：
  - 一次性资产处置收益、政府偶发补贴、公允价值变动损益必须从可持续经营 EBITDA 中剥离单列。
  - 当期应还本息分母为 `0` 时，DSCR 显式标记为 `N/A（当期无到期本息）`，绝不输出无穷大冒充极优信用。
  - **到期墙（Maturity Wall）颗粒度**：全年汇总 DSCR `> 1.3x` 仍可能在某季度集中到期日出现流动性违约；遇大额集中还本或债券回售日，必须下钻到季度/月度核查时点缺口。
  - **逾期与重组定性**：逾期天数（DPD）必须写明观察基准日、合同约定宽限期及扣款冲抵顺序（先息后本或先罚息）；借新还旧或展期重组属于合同修改（Forbearance/Restructuring），不能直接抹去原履约压力记录。

## 3. 抵质押折价瀑布与压力损失情景

| 担保品 / 增信类别 | 必核权属与变现约束 | 常见高估陷阱（必须规避） |
|---|---|---|
| **现金等价物 / 存单质押** | 是否在本机构开户止付、币种错配汇率波动、质押登记完备性 | 将未办妥止付登记的一般结算户存款当成 100% 无风险质押 |
| **应收账款质押** | 账龄分布、买方集中度、关联方交易剔除、确权通知与回款闭环账户 | 对超长账龄或关联方挂账按账面原值计入有效担保 |
| **不动产 / 专用设备抵押** | 抵押顺位（一押 vs 二押余值）、法定优先权（工程款/欠税/职工安置）、法拍周期与折价率 | 按几年前评估原值直接令 `LGD = 0%`，忽略二押顺位扣减前手本息后的真实残值 |
| **关联方 / 集团保证担保** | 保证方式（连带责任 vs 一般保证）、保证人自身独立净现金流与对外或有负债总额 | 同一母公司对多户子公司超额连带互保，经济周期下行时相关性趋近于 1 |

- **情景期望损失边界**：仅在同一时间跨度且明示假设参数下，可用 $\text{EL} = \text{PD} \times \text{LGD} \times \text{EAD}$ 做管理层压力情景对比；未经机构历史违约库校准与前瞻宏观加权，严禁将该情景值称为法定 IFRS 9 预期信用损失拨备或监管资本计量结果。
- **防双重扣减**：设计压力情景时，行业整体营收下滑与第一大客户断约需分设情景或剔除重叠部分，避免对同一笔收入重复扣减。

## 4. 结构化授信建议与动态监测契约（Covenants）

每一条风险缓释建议都必须落到可执行的债项条款与贷后预警触发器（含**指标公式、数据取数源、核查频率、触发阈值与触发后处置动作**），例如：“每季末核查借款主体独立报表净负债/EBITDA 与受限外现金底线；连续两月主回款户流水低于约定比例时启动提款冻结复核”。
