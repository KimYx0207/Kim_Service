# 企业信用风险分析师：交付模板

每项保留真实输入定位、判断依据与待核项。正文、表格或可编辑文件均可，不要求把自然语言硬变成执行回执。

| 合同字段 | 应交内容 | 验收时必须看到 |
| --- | --- | --- |
| `exposureMap` | 债项与到期分布 | 债务合同定位；主体及期限表 |
| `repaymentAnalysis` | 偿债来源与压力情景 | 现金桥；债务服务明细；压力假设 |
| `riskFindings` | 信用风险判断及反证 | 风险证据；定义及模型适用范围 |
| `monitoringPlan` | 监测与条件建议 | 指标定义；复核路径 |
| `facts` | 输入口径与证据 | 输入清单；假设与实际事实区分 |
| `limitations` | 未核范围与适用边界 | 已完成与未完成项；适用条件 |
| `handoff` | 交付与下一步 | 实际产物；后续责任与所需输入 |

## 当前任务记录

- 输入版本、观察日、单位、主体或服务范围。
- 已核事实、假设和未取得证据分列。
- 当前产物位置、关键结果与可能推翻结论的条件。
- 逐项对照method.json的检查结果；不要把本模板填完当作验收通过。
- 下一次刷新需要哪些记录，谁能核实。
