# 企业信用风险分析师：合成交付演练

所有数值、条款、设备、账户和业务对象均为合成教学材料；预期判断尚未经过真实行业任务评测。

## 输入

```json
{
  "borrower": {
    "entity": "合成企业甲",
    "cashAvailableForDebtService": 120,
    "currency": "CNY",
    "unit": "万元",
    "cashHorizon": "未来12个月"
  },
  "facilities": {
    "principalDue": 80,
    "interestDue": 20,
    "horizon": "12个月"
  },
  "policy": {
    "stressCashReduction": 20,
    "approvalThreshold": "未提供",
    "pd": 0.02,
    "lgd": 0.4,
    "ead": 1000,
    "pdHorizon": "未来12个月",
    "eadCurrency": "CNY",
    "eadUnit": "万元",
    "stressDefinition": "该12个月可供偿债现金减少20万元；未指定原因",
    "maturitySchedule": "未提供逐期到期计划"
  }
}
```

## 分析与可复核结果

合成企业甲，单位CNY万元，未来12个月可供债务服务现金120，应还本金80、利息20，基础DSCR=120÷100=1.20。题设压力情景把该期可用现金减少20，压力DSCR=100÷100=1.00。原因未给，不擅自解释为回款延迟或损失。逐期到期计划未给，不能推出哪几个月集中到期，也不能证明每个到期日均有覆盖。
同一12个月时间范围内给定PD=2%、LGD=40%、EAD=1000万元，简单情景EL=0.02×0.40×1000=8万元。参数为题设，不是模型从企业数据估计；未完成会计准则要求的阶段、前瞻情景和折现等处理，不称拨备计量。

## 当前交付字段

- `exposureMap`：facilities给出未来12个月本金80、利息20万元；尚无逐笔债项ID、担保和具体到期日，暂不能完成债项分桶或跨主体担保判断。
- `repaymentAnalysis`：给定可用现金120÷本息100=1.20；压力现金100÷100=1.00。现金金额来自题设，税费、资本开支与营运资本桥未提供，不能称已核财务报表。
- `riskFindings`：同范围参数的简单EL=8万元；逐期断点与担保可执行性未知。没有机构阈值，不给批准或拒贷结论。
- `monitoringPlan`：补逐笔到期日、实际回款、受限现金和担保条款；以每个到期日前的可动用现金复核覆盖，财务数据变化或保证范围变化时重算；阈值依机构policy补入。
- `facts`：本例所有对象和数值为合成，来源是本页input对应字段；未提供的真实文档、观察日或外部事实均不补造。各已给单位、日期和条款版本按原字段保留。
- `limitations`：仅完成所示条件推导与文本分析；未连接实际业务系统、未验证真实来源，未执行外部变更。缺口及其影响已经分布到各领域输出。
- `handoff`：本页作为合成交付示范；实际任务按delivery-template和method.json交同名字段、原材料位置与逐项检查证据。将上述待核材料交当前调用方继续，不创建新的授权或业务状态。

以上覆盖当前合同全部必填字段；它是合成输入的完整交付演练，不是实际业务验收。

## 看起来完整但应拒收

```json
{
  "riskFindings": "DSCR大于1，因此自动批准；有担保所以信用损失为0。"
}
```

忽略到期日、机构阈值、担保可执行性和损失模型前提。

## 材料不全时仍能交什么

- `repaymentAnalysis`：先交到期表与应还本息；现金覆盖暂不判断，列出税费、资本开支和回款需要补的字段。
