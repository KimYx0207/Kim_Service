# 概念讲解与误区诊断：专业方法

知识修订：0.2.0，2026-11-10。本文是本包原创方法与合成算例，不是第三方包副本。

## 输入与适用范围

- 根据学习者当前尝试定位卡点
- 解释一个概念并用新题观察理解；不诊断学习障碍

- `question`：具体概念或题目，保留原条件。 缺失时：先索取需要解释的内容，不猜教材章节。

完整输入/输出仍以同包 capability.json 为准；acceptanceCriteria/handoffContext 若由合同要求，应采用当前任务绑定，不能把材料当授权。

## 领域知识

- 错误答案可能来自概念、符号、计算、单位或题意，不同原因需要不同帮助。先读尝试，选择一个能区分原因的小问题；不要仅因一次算错给学习者贴能力标签。
- 让图、语言和算式指向同一个量。例如1/2÷1/4问半个整体中有几个四分之一个整体，答案2的单位是“份”，不是两个整体。类比须指出对应关系与失效条件；只给口诀会隐藏单位与意义。
- 先演示一例，随后减少提示，换数值或换情境检查迁移。重复原题答案不等于理解；让学习者解释为什么或指出反例。学习建议参考间隔回看和提取练习，但根据实际表现调整，不宣称某种固定学习风格适用。

## 诊断顺序

### locate-error：卡点是概念、符号、计算还是问题理解？

检查：学习者原始答案及过程；题目和已学知识。缺证据时：先给一条区分性追问或温和默认解释，不做能力诊断。

### representation：哪种表征能保持同一个量与单位？

检查：图、实物、语言与算式的对应；类比的适用范围。缺证据时：使用简单可核例子，避免新术语增加负担。

### transfer：脱离示范后能否解释一个变化后的问题？

检查：新问题的作答与理由；反例或逆向检查。缺证据时：交迁移题和检查标准，不写学习者已掌握。

## 决策方法

- **meaning-before-rule**：学习者会套公式但说不清意义时，用一个具体量和图示/语言解释，再映射到公式。拒绝：继续堆公式或把口诀当概念。
- **targeted-help**：错误仅出在一处计算或记号时，修正那一步并保留已经正确的推理。拒绝：从头长篇讲解所有先备知识。
- **fade-support**：示范已理解但尚未独立作答时，给提示更少的迁移题，按表现决定复习。拒绝：用重复例题的答案宣称迁移成功。

## 交付与验收

- `stickingPoint`：以学习者过程为依据，必要时标诊断假设。 不通过情形：无过程就断言其基础差或有学习障碍。
- `explanation`：表征、单位和符号一致，直接解释卡点。 不通过情形：概念偷换或用口诀跳过意义。
- `workedExample`：例题过程可复算，解释每步。 不通过情形：只给结论或把“份”说成整体。
- `transferQuestion`：变化能检验同一概念且不直接泄露答案。 不通过情形：原样重复示范或考未学的额外知识。
- `nextStep`：按不同作答说明下一步检查。 不通过情形：未收到作答就宣布掌握。

## 工具与实际执行

通常可用文本、简单图示和可复算算式。可读取用户指定教材页但不能假称符合未读课程标准；没有图像能力就用清晰的语言表征。涉及具体学生记录只使用当前任务必要信息。

## 正例与反例

以下是作者设计的合成片段，不是模型运行记录，也不是完整正式交付；预期判断仍需独立专业复核。

### unit-of-answer（可接受候选）

学习者把1/2÷1/4=2解释成两个蛋糕。

输入：{"question":"为什么半个蛋糕除以四分之一个会等于2？","currentAttempt":"答案2是不是两个蛋糕？"}

候选输出片段：

```json
{
  "stickingPoint": "算式结果正确，但结果单位应是四分之一蛋糕大小的份数。",
  "workedExample": "半个蛋糕能分成两份，每份四分之一个。2×1/4=1/2核对回原数量。",
  "transferQuestion": "3/4个蛋糕分成每份1/4个，可以分几份？说清答案单位。"
}
```

判断理由：纠正量的意义并检验迁移，不否定已正确的计算。

### formula-only（应拒绝候选）

学习者请求解释分数除法含义。

输入：{"question":"为什么除以分数要这样算？","currentAttempt":"我记得颠倒相乘，但不知道为什么。"}

候选输出片段：

```json
{
  "explanation": "口诀记住就行，除以分数就是颠倒相乘。",
  "nextStep": "你已经掌握了，不用做新题。"
}
```

判断理由：重复已会口诀，没有解决含义，也没有独立理解证据。

## 失败与人工边界

- 疑似学习障碍、心理或医学问题不能由一次练习诊断，应由合格人员评估。
- 正式教学与考试适配由负责教师按课程和学习者需要确认。
- 必要事实/能力缺失时交具体影响和下一步，不伪造执行；只停止受影响部分，整体调度由调用方决定。
- 专业效果状态是 `not_evaluated`；合同验证和资料完整字节交接只证明结构与来源运输，不能代替真实任务质量。
