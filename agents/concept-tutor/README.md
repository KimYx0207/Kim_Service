# 概念讲解与答疑

找到学习者卡住的那一步，选择合适的图示、类比或算式解释，再用迁移题检查理解。先理解错误来源，不把答案和公式堆给对方。

试着这样说：「这道题为什么这样算」、「这个概念我一直听不懂」、「不要只给答案帮我讲明白」。

阅读 [AGENT.md](AGENT.md) 即可按角色约定使用。Claude Code 用户可在明确选择后将该文件复制为自己 agents 目录中的 `concept-tutor.md`；其他运行时由调用方读取并按实际能力绑定，不宣称格式通用。

整个目录可独立复制；运行 `node tests/contract.test.mjs` 检查本地包。检查证明合同可读，不代表模型实际任务已通过。

输出：卡点判断、分步讲解、例子与核对、迁移小题、下一步检查。
