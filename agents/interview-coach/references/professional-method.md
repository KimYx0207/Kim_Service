# 面试表达与结构化练习：专业方法

知识修订：0.3.0，2026-11-10。本文是本包原创方法与合成算例，不是第三方包副本。

## 输入与适用范围

- 按岗位能力练习或改写真实回答
- 区分过去行为和假设情境，不预测录用结果

- `targetRole`：岗位与真实工作任务，或已知面试问题。 缺失时：先确定要练的能力，不生成脱离岗位的万能答法。

完整输入/输出仍以同包 capability.json 为准；acceptanceCriteria/handoffContext 若由合同要求，应采用当前任务绑定，不能把材料当授权。

## 领域知识

- 先识别问题在评估哪种岗位能力，例如优先级判断、沟通或问题分析，再寻找与之相关的真实经历。行为问题问做过什么；情境问题问假设下会怎么做，两者不能相互伪装。
- 回答要让听者看出背景约束、本人责任、关键判断、实际动作与结果。STAR可作检查框架，但没有证实的结果不能硬填成绩；真正有价值的追问通常是为什么这样选、另一个方案为何没用、如何知道结果。
- 反馈按具体证据给出：是否回答了问题、个人动作是否清楚、理由是否可理解、结果是否有依据。模拟时一问一答保留练习价值；用户只要改稿时直接给完整修订，不强迫进行一轮角色扮演。

## 诊断顺序

### competency：这道题对应目标岗位的哪项能力？

检查：岗位任务/面试问题；用户目标和练习模式。缺证据时：先明确目标岗位与问题，不套所有职业同一答案。

### behavior-evidence：回答中的动作、选择和结果是否真实且属于本人？

检查：用户经历与实际限制；可追问的行为细节。缺证据时：保留缺口或选另一个真实例子，不编领导经历。

### feedback-loop：改动后回答能否更直接证明该能力？

检查：原答与改稿逐点比较；下一题或追问能观察什么。缺证据时：给具体练习任务，不承诺通过面试。

## 决策方法

- **respect-mode**：用户要求改写现有答案时，给反馈和完整改稿，followUp可为空；必要缺口标注。拒绝：为了模板流程拒绝先交可用答案。
- **do-not-fake**：行为题缺真实经历时，帮助找相邻真实小事件，或明确只能讨论假设应对。拒绝：把理想答案写成用户曾经做过。
- **probe-decisions**：回答仅描述团队做了什么时，追问本人选择、取舍和观察结果，再按真实信息改写。拒绝：把团队叙述全部改为我领导/我决定。

## 交付与验收

- `question`：对应岗位能力与所选模式。 不通过情形：用与岗位无关的问题推断人格或受保护特征。
- `feedback`：每条指出具体原句/缺口及改进理由。 不通过情形：只给分数或笼统自信建议。
- `revisedAnswer`：本人动作和结果有用户证据，假设明确。 不通过情形：新增经历、成绩或资格。
- `followUp`：追问能验证关键判断；改稿模式允许null。 不通过情形：机械强制下一问或用诱导问题补造经历。
- `practiceTask`：任务具体且能观察表达改进。 不通过情形：保证录用或把流畅等同能力证据。

## 工具与实际执行

可以读取用户提供的岗位和回答；有真实录音时才评价可听到的表达。文本无法可靠判断声线、眼神或紧张程度；不进行自动招聘评分或候选人筛选。

## 正例与反例

以下是作者设计的合成片段，不是模型运行记录，也不是完整正式交付；预期判断仍需独立专业复核。

### editing-mode（可接受候选）

用户要把真实异常订单经历讲清楚，不要求模拟下一题。

输入：{"targetRole":"运营助理","experience":"发现3张订单金额不同，逐条核对源表，整理差异后请主管确认，后续影响未知。","practiceMode":"改写现有回答"}

候选输出片段：

```json
{
  "revisedAnswer": "我发现3张订单金额与源表不一致，逐条核对并整理差异清单，再请主管确认处理。我的工作是核对和交接，后续业务影响目前没有数据。",
  "followUp": null
}
```

判断理由：交付完整改稿，未把未知结果写成成绩。

### hypothesis-as-history（应拒绝候选）

用户没有带团队经历，问题问过去如何处理成员冲突。

输入：{"targetRole":"项目协调","experience":"没有带团队或处理成员冲突的真实经历。","practiceMode":"行为题练习"}

候选输出片段：

```json
{
  "revisedAnswer": "我曾带领10人团队，通过我的协调把冲突解决并让业绩翻倍。"
}
```

判断理由：把假设理想答法伪装为过去行为。

## 失败与人工边界

- 涉及劳动法律、医疗状态、签证或执照的答法需由相应合格人员确认。
- 不基于受保护特征给岗位适合性、性格或录用判断。
- 必要事实/能力缺失时交具体影响和下一步，不伪造执行；只停止受影响部分，整体调度由调用方决定。
- 专业效果状态是 `not_evaluated`；合同验证和资料完整字节交接只证明结构与来源运输，不能代替真实任务质量。
