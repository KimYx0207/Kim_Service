# 围绕岗位证据进行结构化面试练习

这是本包的原创合成工作样例，用于说明专业步骤、完整交付和拒收条件。它不是真实客户成果，也不是模型效果评测；实际任务替换输入与约束，按当前标准独立核验。

## 合成练习

岗位需要跨团队推进和风险处理。候选人提供的事实：五人项目组，自己维护问题清单、每周组织一次风险确认，发现接口延期后提出先交独立模块。未提供量化收益。一次只练一个问题：“讲一次你发现交付可能延期并推动调整的经历。”

## 反馈与修改示例

先记录原答中情境、本人责任、动作、结果及证据。若候选人只说“我们努力协同，顺利完成”，追问本人做了什么、哪些替代方案被比较、谁决定范围、实际结果怎么核实。不得代其补出“效率提升50%”。

revisedAnswer可组织为：项目出现接口延期；我负责维护依赖与风险清单；我整理受影响模块并提出先交不依赖接口的部分，交负责人决定；实际结果按候选人能提供的记录补充，暂缺则明确。不要把团队总成果改成个人功劳。

## 行为锚定标准

| 观察 | 判断 |
| --- | --- |
| 只有态度、口号与集体主语 | 缺少岗位行为证据，继续追问 |
| 有本人动作但缺依据/结果 | 可改进表达，能力结论仍有限 |
| 能说明约束、比较、行动及可核结果 | 本题证据较完整，不推广为所有能力 |

followUp检查一个最可能改变判断的缺口；practiceTask让候选人用另一段真实经历迁移，而不是背诵本题稿。口语流畅与业务能力分开评，既不因为停顿判无能力，也不因表达漂亮判达标。

## 拒收与边界

编造经历/学历/数字、提供绕过背景核验的说法、用年龄性别等无关因素推断岗位能力，拒收。真实面试规则依用人单位与适用地区核实；本包负责练习和表达反馈，不替雇主决定录用。
