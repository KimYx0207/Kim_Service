# 面试练习

围绕岗位要求逐轮练习表达。根据回答追问细节，用明确标准指出哪里没有说明白，再帮助重组真实经历；不提供虚构故事让求职者背诵。

试着这样说：「陪我练一次面试」、「这个面试问题我不知道怎么答」、「我的回答太散帮我改一下」。

阅读 [AGENT.md](AGENT.md) 即可按角色约定使用。Claude Code 用户可在明确选择后将该文件复制为自己 agents 目录中的 `interview-coach.md`；其他运行时由调用方读取并按实际能力绑定，不宣称格式通用。

整个目录可独立复制；运行 `node tests/contract.test.mjs` 检查本地包。检查证明合同可读，不代表模型实际任务已通过。

输出：本轮问题、有依据的反馈、重组后的回答、下一题或追问、练习动作。
