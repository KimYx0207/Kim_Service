# 把最低单价、最低现金支出和可交付报价分开

这是本包的原创合成工作样例，用于说明专业步骤、完整交付和拒收条件。它不是真实客户成果，也不是模型效果评测；实际任务替换输入与约束，按当前标准独立核验。

## 合成任务

需求500件同规格物料，五天内交付，币种CNY。A报价9元/件、MOQ600件、运费180元、交期7天；B报价10元/件、MOQ500件、运费0元、交期4天。假定本例两家税口径一致、质量规格可比；实际任务须逐项查证。

## 可交付对照表

| 项目 | A | B |
| --- | ---: | ---: |
| 本次需采购数量 | 600 | 500 |
| 货款 | 5400 | 5000 |
| 已知现金支出 | 5580 | 5000 |
| 超需求库存 | 100件 | 0件 |
| 交期 | 7天，不满足本例5天 | 4天，满足已知要求 |

不能用A的9元乘需求500得到4500后宣布最便宜；MOQ约束决定本次支出。A每购入件已知成本为9.30元，本次500件需求对应的现金占用为11.16元/需求件，二者含义不同，不得混写为单位成本。剩余100件具有未知未来用途，不能自动抵减本次现金支出。

## 判断流程

先核规格、计量单位、报价有效期、税、币种/汇率日期、MOQ/包装倍数、质量验收、交期起算点、付款条件、运费与售后。硬约束先筛可行性，随后比较可行报价的总成本与风险。若不同币种，保持原币金额与转换依据；没有同一时点/来源的汇率，不直接排出精确名次。

facts只列供应商原话和证据；normalizedQuotes显示转换及已知/未知项；constraints给不满足的具体条件；comparison分别比较成本、交付与风险；recommendations给条件式建议和待澄清项。本例在已知条件下优先B，仍需确认运费“0”是否覆盖目的地，以及4天是发货还是到货。

## 变体与拒收

若B运费未知，不当0，给A/B可比较部分与改变排序的运费阈值。若A可拆单，要求真实拆单报价再重算，不能代供应商承诺。不同质量等级先补规格一致性，历史延误记录与本次报价承诺分开。加权评分的维度和权重需在看排名前固定；交期硬约束不能被低价得分抵消。
