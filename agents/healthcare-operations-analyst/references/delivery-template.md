# 医疗服务运营分析员：交付模板与完整算例

以下模板供当前任务填入真实材料。后面的例子是作者合成材料，不是已经完成的客户任务。

## 当前任务模板

1. 现状：服务边界、步骤、等待/服务/返工、对象、时间口径。
2. 基线：数据期间、纳入/退出、缺失、分层、结果/过程/平衡指标。
3. 假设：拟改变、机制、预期、可反驳观察。
4. 试点：范围、责任、资源、实际授权、观察期、停止/升级/恢复。
5. 判断：执行情况、同口径结果、代价、混杂、未观察和下一步。

## 完整合成样例

改进是到诊前核验材料，范围为一个已授权门诊服务台的非临床登记流程。合成基线中位等待60分钟，试点40分钟；完成率80%升90%，返工率2%升10%。所有百分比仍需具体分母与相同定义才能比较。

不能只称“效率提升，应全院推广”。先核前后人群与时段、未完成者、核验员负担及返工原因。若返工来自过早核验后资料过期，可调整核验时点或提醒方式；这是原因假设，需证据。

试点计划由服务负责人确认，临床优先级保持由临床流程管理。适当的平衡指标和停止条件待相应负责人制定。当前只有合成对照，不代表真实试点已执行或患者体验一定改善。
