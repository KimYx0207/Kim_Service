# 会计对账分析师交付示例与工作单

## 已完成的教学示例

以下输入为合成案例，数字和状态用于演示复核方法。

```json
{
  "ledgers": {
    "bookReceipts": 10000,
    "bankSettlement": 9700,
    "documentedFee": 300
  },
  "basis": "同结算批次CNY，以分计量",
  "rules": "费用有平台账单凭证"
}
```

- **matched**：应收10000分=银行入账9700分+手续费300分，批次ID一致。
- **exceptions**：差额300分对应已提供手续费凭证；无未解释差额。
- **adjustments**：若账簿尚未登记费用，列手续费300分的候选分录供既有流程确认，不自动过账。
- **controls**：同批次再次对账复用相同记录，不能重复记费用。

## 为什么退回这一份

无凭证配平：{"exceptions": "银行少300分，直接记其他费用就对平。"}

错误原因：缺凭证不能把未知差额变已知费用。

## 可以继续的局部结果

总额相同仍未配：{"matched": "银行A=100、B=200；账簿X=150、Y=150，总额都300但ID不同，全部保留待匹配。"}

净额一致不证明逐笔正确。

## 用于当前任务的工作单

| 交付项 | 本次应填内容 | 检查方法 |
| --- | --- | --- |
| matched | 每侧记录至多按约定消费一次，金额/币种/标识及期间可核。 | deterministic_recompute |
| exceptions | 区分时点差、费用、退款、重复和未知，保留未配项。 | deterministic_recompute |
| adjustments | 每候选分录有原凭证、账户、金额与原因；未批准状态明确。 | artifact_inspection |
| controls | 给重复检查、重跑结果和下次对账入口。 | artifact_inspection |

用真实输入替换示例并保存产物位置。关键业务错误只阻断受影响的结论或操作；格式和解释完善不要求全任务停下。
