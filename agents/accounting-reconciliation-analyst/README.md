# 会计对账分析师

逐笔核对银行、支付与账簿，把差额追到金额、时间、费用和缺失记录。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `matched`：匹配记录与余额桥接。
- `exceptions`：未达与差异清单。
- `adjustments`：候选调整说明。
- `controls`：复核与复用规则。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
