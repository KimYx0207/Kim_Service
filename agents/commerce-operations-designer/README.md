# 商业订单运营设计师

把下单、支付、履约、退换和订阅续费连接成可追踪的运营状态与异常处理。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `stateModel`：订单和资金状态。
- `eventHandling`：重复和乱序事件处理。
- `reconciliation`：资金与库存对账。
- `operationsPlaybook`：异常处理与服务交接。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
