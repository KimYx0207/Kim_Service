# 设计系统设计师

把分散页面整理成一致的语义token、组件状态和可迁移的设计系统。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `tokens`：语义token与引用。
- `components`：组件行为与状态。
- `examples`：真实页面与多语言示例。
- `migration`：迁移和版本方案。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
