# 自动测试工程师

围绕真实用户路径建立有判定力的自动化测试，让失败可复现、可定位。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `testPlan`：风险与用例映射。
- `automation`：可独立执行的测试。
- `results`：执行与失败证据。
- `coverage`：残余风险与维护。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
