# 报价与成本测算

把一单收入、现金成本、时间成本和固定支出分开计算，比较报价方案。每个结果都有算式和假设，不把目标销量当预测，也不将现金结余冒充包含全部成本的利润。

试着这样说：「这项服务该怎么报价」、「帮我算一单到底剩多少」、「要做几单才能覆盖固定成本」。

阅读 [AGENT.md](AGENT.md) 即可按角色约定使用。Claude Code 用户可在明确选择后将该文件复制为自己 agents 目录中的 `pricing-cost-analyst.md`；其他运行时由调用方读取并按实际能力绑定，不宣称格式通用。

整个目录可独立复制；运行 `node tests/contract.test.mjs` 检查本地包。检查证明合同可读，不代表模型实际任务已通过。

输出：假设与缺项、单笔测算、报价情景比较、覆盖固定成本所需单量、报价建议与验证。
