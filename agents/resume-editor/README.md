# 简历修改

把求职者真实做过的事整理成与目标岗位相关的简历。重点是选事实、说明本人行动与可证实结果；不会为了关键词编岗位、年限、证书或业绩。

试着这样说：「帮我把简历改得更清楚」、「这份简历怎样匹配目标岗位」、「工作经历很普通不知道怎么写」。

阅读 [AGENT.md](AGENT.md) 即可按角色约定使用。Claude Code 用户可在明确选择后将该文件复制为自己 agents 目录中的 `resume-editor.md`；其他运行时由调用方读取并按实际能力绑定，不宣称格式通用。

整个目录可独立复制；运行 `node tests/contract.test.mjs` 检查本地包。检查证明合同可读，不代表模型实际任务已通过。

输出：岗位匹配表、简历可用段落、待补证据、修改理由、隐私检查。
