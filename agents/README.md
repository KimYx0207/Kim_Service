# 找一个能帮上忙的角色

不用记英文名称，先看自己想做什么。每个角色有完整例子，告诉你要提供什么、能拿到什么。这里是用途目录；使用 Meta_Kim 时由它根据需求、材料和可用工具选择角色。

| 你的事情 | 可以这样说 | 角色 | 会交给你什么 |
|---|---|---|---|
| 自媒体 | 不知道下一周发什么 | [选题策划](topic-planner) | 选题、切入角度、素材和排期 |
| 自媒体 | 正文有了，标题和封面怎么写 | [标题封面](headline-cover-optimizer) | 标题候选、封面文字与内容核对 |
| 自媒体 | 把这个选题写成口播或图文 | [脚本文案](script-writer) | 开头、正文或分镜、口播与拍摄清单 |
| 电商 | 把商品参数写成顾客看得懂的详情页 | [商品页文案](product-listing-writer) | 事实、标题、卖点证据和详情正文 |
| 电商 | 客户催发货，这句话怎么回 | [客服回复](customer-service-writer) | 回复草稿、处理分支和升级条件 |
| 电商 | 按 SKU 和渠道复盘这周单量，利润资料不全也说清楚 | [店铺数据复盘](store-performance-analyst) | 可比口径、核算依据、收入与成本缺项、异常解释和低成本行动 |
| 采购供应链 | 比较几家同规格报价，算到货成本和交期，再看权重变了怎么选 | [供应商比较](supplier-comparison-analyst) | 包数与起订量、成本缺项、交期证据、条件比较和试单建议 |
| 求职职场 | 按目标岗位帮我改简历 | [简历修改](resume-editor) | 岗位匹配、可用段落和待补证据 |
| 求职职场 | 模拟面试，帮我练回答 | [面试练习](interview-coach) | 逐题练习、有依据的反馈与改写 |
| 求职职场 | 把这些进度写成周报或邮件 | [职场写作](workplace-writer) | 正文、状态核对和需要对方确认的事 |
| 教育 | 明天这节课怎么安排 | [备课设计](lesson-planner) | 目标、课堂流程、提问和离堂检查 |
| 教育 | 这个知识点我没懂 | [知识讲解](concept-tutor) | 分步解释、完整例子和迁移小题 |
| 教育 | 围绕这个知识点出几道练习 | [练习设计](exercise-designer) | 原创题目、答案解析和常见误解 |
| 副业创业 | 几个副业方向，哪个值得先试 | [方向评估](side-business-evaluator) | 条件比较、首试方向和小成本验证 |
| 副业创业 | 方向定了，帮我安排第一周 | [启动计划](launch-planner) | 第一版范围、日程、预算和检查标准 |
| 副业创业 | 这项服务卖多少钱才划算 | [报价与成本](pricing-cost-analyst) | 现金与时间成本、情景比较和报价前提 |


| 产品与系统 | 先确定最小交付和接口/迁移边界 | [产品架构](product-architect) | 范围、状态与接口决策、回滚和验收标准 |
| 交互与视觉 | 把完整流程和动效做清楚 | [交互设计](interaction-designer) | 状态、token、响应式、可访问性和截图待验项 |
| 前端工程 | 按已定接口和交互修复或实现前端 | [前端实现](frontend-engineer) | 限定补丁、最终代码测试及浏览器证据 |
| 后端与数据 | 做服务、迁移、幂等和隔离验证 | [后端数据](backend-data-engineer) | 服务补丁、迁移/回滚和失败路径测试 |
| 图像音视频 | 按授权素材制作流程与横竖版产物 | [媒体制作](media-production-engineer) | 参数化工作流、导出、探测与视听质检 |
| 量化研究 | 核查数据时点、成本和回测风险 | [量化研究](quantitative-researcher) | 研究方法、有限核算与复现材料；不交易 |
| 来源与平台 | 核原帖、复盘、修订或准备人工交接 | [证据核查](source-evidence-analyst) | 来源事实、冲突、范围和未核项 |
| 交付验收 | 实际检查产物是否满足清单 | [交付核验](delivery-verifier) | 文件hash、有限语义与回执一致性检查 |

先提供事实和限制即可，不必补出没有的数据。角色交付的是内容、解释或建议；发送、发布、下单和付款由你另行决定。

各包可独立阅读和复制，使用说明、许可及检查入口都在包内。当前包结构可验证，各运行时的原生加载及模型表现仍待实测。维护规范见 [Agent 包契约](../docs/agent-pack-contract.md)。

新专业方法的组合、宿主工具绑定和共享资源交接见 [任务交付指南](../docs/task-agent-delivery.md)。只读 Agent 不因工具槽获得写入权限；真实执行由宿主按当前任务授权绑定。
