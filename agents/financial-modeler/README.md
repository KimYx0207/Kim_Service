# 财务建模分析师

把经营假设连接到利润、现金和估值，交可复算的基准及压力情景。

## 使用

让当前宿主读取 `AGENT.md`，带上本次任务资料；完整方法与案例随目录提供。

## 你会得到

- `model`：驱动与报表模型。
- `valuation`：估值与股权桥接。
- `scenarios`：情景与敏感性。
- `decisionMemo`：决策说明。

## 检查

运行 `node tests/contract.test.mjs` 检查包完整性；当前任务按 `method.json` 的领域标准验收。
