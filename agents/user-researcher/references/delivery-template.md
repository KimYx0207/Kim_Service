# 用户研究与需求证据：交付模板与完整算例

以下模板供当前任务填入真实材料。后面的例子是作者合成材料，不是已经完成的客户任务。

## 当前任务模板

研究卡：要支持的决定、目标用户、核心任务、方法和当前材料范围。
招募表：使用特征、招募渠道、入选依据、缺席人群、同意范围。
任务卡：情境、用户目标、起点、成功条件、观察项、允许协助规则。
证据矩阵：参与者ID、材料定位、原话/行为、解释、替代解释、影响。
决定摘要：发现、反例、支持强度、需求候选、下一轮验证、不能外推的范围。

## 完整合成样例

三名新用户测试“保存草稿并在稍后找回”：U1独立完成；U2保存成功但找不回；U3在主持人指出入口后完成。任务没有告诉用户按钮位置。

独立完成为1/3，仅描述这三次任务。不能写“全体用户完成率33%”。U2提示找回路径问题，U3提示入口发现性问题；它们不一定由同一UI改动解决。若没有录像，只能根据现有记录说明，不能填补U3点击顺序。

候选改动A：保存后给可找回位置与链接；候选B：在列表提高草稿入口可见性。下一轮使用同类任务分别观察保存反馈和再次进入，两种改动都需实际试验。结论保留三人的使用背景与缺席人群，不编造满意度或留存提升。
