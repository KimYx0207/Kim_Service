# 标题封面与承诺一致性：专业方法

知识修订：0.2.0，2026-11-10。本文是本包原创方法与合成算例，不是第三方包副本。

## 输入与适用范围

- 根据实际正文提出标题与封面方向
- 核对一致性，提供可检验选择而非流量保证

- `bodyOrKeyPoints`：正文实际信息与可兑现的结果。 缺失时：先索取正文或关键事实，不能从空题目保证效果。

完整输入/输出仍以同包 capability.json 为准；acceptanceCriteria/handoffContext 若由合同要求，应采用当前任务绑定，不能把材料当授权。

## 领域知识

- 标题把正文可兑现的结果传给目标读者，封面补充一条关键信息或视觉证据。数字、对比、人物和“之前/之后”都在表达声明：素材只展示练习，不能包装为真实用户效果。标题与封面重复所有文字通常不能增加信息。
- 先选具体且准确的承诺，再按移动端阅读、重点和素材条件设计。版式可选问题、过程、结果或物件证据，不能机械限定为三套布局。缩略预览、文字对比、裁切安全区需要实际图像检查；文案方案不是已生成封面。
- CTR需要曝光定义和流量来源。推荐扩展到较陌生的人群时，CTR可能下降；改变标题前后的观众也可能不同。单次前后对比不能证明因果，平台自己的实验也仅适用于其实际支持的范围。不得把不准确标题必然导致某种全平台惩罚写成事实。

## 诊断顺序

### promise：正文真实兑现什么结果或问题？

检查：完整正文/关键段落；数字、对象和条件的证据。缺证据时：先做保守准确的承诺，不能靠标题补正文没有的价值。

### thumbnail-context：缩略图在什么位置被谁看到？

检查：平台展示尺寸与实际素材；目标读者、裁切和文字层级。缺证据时：交文字/构图方案并标未视觉核验，不假造截图。

### test-context：现有点击数据能支持改哪个因素？

检查：曝光量、来源与相同时段/人群；标题封面版本及实验条件。缺证据时：给待测假设，不称推荐已是赢家。

## 决策方法

- **truth-before-strength**：强标题暗示的效果超出内容时，删去未经证实的保证、数字和绝对化关系。拒绝：用标题党弥补正文缺证据。
- **complement**：标题已说清主题但封面可展示关键证据时，用有限主信息和实际视觉证据补充，检查缩小后可读性。拒绝：把所有标题再复制一遍或空喊高级。
- **no-causal-shortcut**：前后CTR差异同时有人群/来源变化时，按来源和实验条件比较，明确因果尚未验证。拒绝：宣布CTR下降必然由标题或平台惩罚造成。

## 交付与验收

- `promise`：标题封面的共同承诺可在正文定位。 不通过情形：暗示正文没有的收益或因果。
- `titleCandidates`：不同表达仍保持对象、条件与证据一致。 不通过情形：换词但都依赖未证实的数字。
- `recommended`：给出适合当前读者/材料的理由与待测点。 不通过情形：声称已经证明点击率最高。
- `coverOptions`：构图、文案、素材及实际制作状态明确。 不通过情形：把设计描述当成已交付封面图。
- `consistencyCheck`：逐项检查数字、人物、结果、限定条件。 不通过情形：只勾选字段齐全，不核正文承诺。

## 工具与实际执行

可读取正文和用户图片，并在实际可用时做缩略视觉检查。平台规范需核当前官方说明；无实验权限只交试验方案。不会自动发布、更换线上标题或伪造封面效果图。

## 正例与反例

以下是作者设计的合成片段，不是模型运行记录，也不是完整正式交付；预期判断仍需独立专业复核。

### bounded-title（可接受候选）

正文演示三步核对CSV导出，没有经营效果研究。

输入：{"bodyOrKeyPoints":"演示下载CSV、核对行数、检查编码，全部使用合成数据","platform":"教程文章","goal":"让新手愿意打开并按步骤检查"}

候选输出片段：

```json
{
  "promise": "教新手核对一次CSV导出是否完整",
  "recommended": {
    "main": "CSV下载后，先检查这三件事",
    "alternate": "给新手的CSV导出核对步骤",
    "reason": "承诺对应正文三项检查；点击效果未验证"
  },
  "coverOptions": [
    {
      "coverText": "CSV下载后检查",
      "layout": "合成文件截图与局部标注",
      "visualAnchor": "圈出行数与编码位置",
      "materialsNeeded": "标明合成的CSV截图，实际缩略可读性待核"
    },
    {
      "coverText": "导出后核对三步",
      "layout": "三步流程图",
      "visualAnchor": "下载、核行数、查编码的顺序",
      "materialsNeeded": "原创图形；当前只交构图说明，未渲染"
    }
  ]
}
```

判断理由：推荐理由来自内容与读者任务，未凭空承诺收益。

### ctr-confound（应拒绝候选）

旧标题100次曝光20点击，新标题1000次曝光100点击，流量来源不同。

输入：{"bodyOrKeyPoints":"同一篇教程","currentTitle":"新手导出检查","goal":"解释CTR从20%降到10%","audience":"新版本拓展了陌生推荐流量"}

候选输出片段：

```json
{
  "recommended": {
    "main": "立即换回旧标题",
    "alternate": "停止发这类教程",
    "reason": "新标题必然更差，平台已经降权。"
  }
}
```

判断理由：受众和曝光构成改变，数据不能证明标题因果或平台处罚。

## 失败与人工边界

- 涉及健康、法律、投资或其他受规范宣传的承诺，需要相关专业审核。
- 人物图片、商标和真实对比结果需核实使用与声明范围。
- 必要事实/能力缺失时交具体影响和下一步，不伪造执行；只停止受影响部分，整体调度由调用方决定。
- 专业效果状态是 `not_evaluated`；合同验证和资料完整字节交接只证明结构与来源运输，不能代替真实任务质量。
