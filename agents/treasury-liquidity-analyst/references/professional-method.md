# 企业资金与流动性分析师：专业方法

把各账户期初非受限现金、经营收付款、税费薪资刚性支出、债务还本付息与授信提款条件放入同一时间轴现金梯（Cash Ladder），精准定位流动性缺口最早发生的具体日期、币种与主体，并给出缺口发生前可落地的资金调度方案。

## 1. 资金梯度的最小核算单元与现金可用性

企业账面合并货币资金充裕却发生技术性违约，核心原因通常是**受限、跨主体隔离或跨币种不可即时兑换**。每笔现金流记录至少绑定：`法人主体 + 币种 + 预计结算日 + 现金流唯一 ID + 方向（流入/流出）+ 确定性等级 + 来源依据`。

$$\text{期初可自由动用现金} = \text{已核对银行对账单余额} - \text{受限资金（承兑保证金 / 司法冻结 / 专项监管户 / 质押存单）} - \text{日内清算最低备付金}$$

- **受限资金释放硬规则**：受限资金只能在对应保证金到期解付日或监管解除条件满足日转入可用池，严禁凭管理层主观意愿提前计入期初可用额。
- **原币独立滚动与折算边界**：多币种业务必须先按原币（CNY / USD / EUR 等）独立跑完每期净头寸：
  $$\text{期末可用现金}_{c,t} = \text{期初可用现金}_{c,t} + \text{确定及已纳入流入}_{c,t} - \text{刚性及计划流出}_{c,t}$$
  只有具备真实换汇额度、跨境资金池通道且计入换汇交割时滞（如 `T+2`）时，盈余币种才能跨币填补缺口；否则汇总折算本位币仅作管理展示，原币缺口必须原样保留告警。

## 2. 13 周滚动现金梯与大额到期日级下钻

标准流动性管理采用 **13 周逐周滚动视图**，但在以下两类窗口必须拆细到**逐日（Daily）梯度**：
1. 存在大额贷款到期、债券兑付、集中退税或季度末缴税、发薪日先于大客户回款日的周次（例如周五回款 5,000 万，但周二刚性发薪缴税 3,000 万——周度汇总看似净盈余 +2,000 万，周二当天实际已穿底违约）。
2. 可用现金缓冲接近管理层设定的**最低安全现金红线（Minimum Cash Buffer）**的区间。最低安全红线依据企业实际结算波动与输入政策设定，不硬套拍脑袋的固定行业百分比。

## 3. 压力情景建模规则：区分“时间平移”与“永久减损”

吸收 Open Source Risk Engine（ORE）将底层头寸数据、情景参数配置与计算结果严格解耦的架构思路（本包不内置衍生品定价引擎），建立可审计情景：

| 冲击类型 | 正确账务平移 / 调整方式 | 常见建模错误（必须拦截） |
|---|---|---|
| **核心客户延迟回款（如推迟 2~4 周）** | 保留原 `cashFlowId` 与合同金额不变，仅将预计结算日向后平移至新桶；跨出观察窗口期末的部分单列“期末在途未达” | 直接删掉该笔现金流导致应收总额凭空蒸发，或改完日期后连带重复扣减一次坏账 |
| **客户实质违约 / 订单取消** | 按违约比例调减该 `cashFlowId` 流入金额，同时联动调整与之直接挂钩的变动采购/税费流出（若尚未发生） | 既把整笔回款延后，又在同一笔上重复叠加 100% 违约扣减 |
| **未承诺授信冻结 vs 已承诺授信提款** | 银行尚可单方撤销的敞口额度（Uncommitted Line）在压力情景下可动用额归零；已签字承诺额度（Committed RCF）仍须核查先决条件与财务契约（MAC / Covenants） | 把意向性授信批复函直接算作随时可提现的银行存款 |
| **浮动利率跳升** | 仅对观察期内重定价日到来的浮动利率债项及新提款部分重算利息流出 | 对已锁定的固定利率存量债项一刀切上调付息额 |

## 4. 缺口缓解工具箱与滚动预测偏差复盘（Variance Bridge）

- **生效时效硬门禁**：任何缓解动作（贴现/保理提前回款、与非核心供应商协商展期、动用已承诺循环授信、集团内合规委贷划转）的交割到账日必须**早于首次缺口发生日**，并列明融资成本、审批前置条件与商业副作用（如丧失现金折扣或影响供应商排产）。
- **预测偏差三分法复盘**：每次用新一周实际数滚动更新时，严禁静默覆盖上周预测基线；必须将“实际 vs 上期预测”差异拆解为三栏：① **时点差（Timing Variance，提前或延后到账）**、② **金额差（Permanent Volume/Price Variance）**、③ **范围新增/漏报（Scope Change）**，持续校准业务部门报数偏差。
