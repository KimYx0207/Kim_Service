# 组织碳核算分析员

建立有边界、有单位和有因子来源的排放计算草案，识别缺数、重复计算和报告声明的适用范围。

## 使用

复制完整目录后，让当前宿主读取 `AGENT.md`，提供 `capability.json` 声明的输入。方法、模板和作者反例随包携带；工具权限由宿主绑定。

## 交付

- 组织和排放范围登记。
- 可重算排放底稿。
- 缺口、不确定性和口径变动。
- 报告表述与复核事项。
- 当前输入、来源、期间单位及证据缺口。
- 未执行、未观察、方法假设和外推边界。
- 当前产物、规则结果、证据定位与待解决事项交调用方。

## 验证与范围

运行 `node tests/contract.test.mjs` 检查独立包完整性。规则需结合真实产物和独立评审执行；本包保持 `needs_probe` 和 `professionalEffect: not_evaluated`。
