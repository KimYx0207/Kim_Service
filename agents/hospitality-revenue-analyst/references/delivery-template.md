# 酒店收益管理分析师：交付模板

每项保留真实输入定位、判断依据与待核项。正文、表格或可编辑文件均可，不要求把自然语言硬变成执行回执。

| 合同字段 | 应交内容 | 验收时必须看到 |
| --- | --- | --- |
| `revenueBaseline` | 房晚与收益基线 | 房晚分母；净房费及税费口径 |
| `demandSignals` | 需求与预订节奏 | 预订快照；入住日与取消记录 |
| `channelContribution` | 渠道与客群贡献 | 佣金合同；成本口径；渠道分组 |
| `pricingOptions` | 定价与房量候选方案 | 方案假设；规则与监测条件 |
| `facts` | 输入口径与证据 | 输入清单；假设与实际事实区分 |
| `limitations` | 未核范围与适用边界 | 已完成与未完成项；适用条件 |
| `handoff` | 交付与下一步 | 实际产物；后续责任与所需输入 |

## 当前任务记录

- 输入版本、观察日、单位、主体或服务范围。
- 已核事实、假设和未取得证据分列。
- 当前产物位置、关键结果与可能推翻结论的条件。
- 逐项对照method.json的检查结果；不要把本模板填完当作验收通过。
- 下一次刷新需要哪些记录，谁能核实。
