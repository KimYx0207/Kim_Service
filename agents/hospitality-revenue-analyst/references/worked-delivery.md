# 酒店收益管理分析师：合成交付演练

所有数值、条款、设备、账户和业务对象均为合成教学材料；预期判断尚未经过真实行业任务评测。

## 输入

```json
{
  "roomInventory": {
    "availableRoomNights": 100,
    "outOfOrderTreatment": "已在可售量剔除"
  },
  "reservations": {
    "soldRoomNights": 80,
    "roomRevenue": 40000,
    "channelA": {
      "nights": 40,
      "roomRate": 500,
      "commission": 0.15
    },
    "direct": {
      "nights": 40,
      "roomRate": 500
    },
    "occupiedRoomNights": 80,
    "roomRevenueBasis": "已扣税费退款及非房费服务，未扣渠道佣金；80房晚均实际入住"
  },
  "pricingPolicy": {
    "currency": "CNY",
    "variableCostPerOccupiedNight": 100,
    "fixedCosts": "未提供"
  }
}
```

## 分析与可复核结果

合成酒店单日可售100房晚，售出且实际入住80房晚，题设房费已扣税费退款及非房费服务、未扣渠道佣金，共40000元：入住率80%，ADR=500元，RevPAR=400元。A渠道40房晚，每晚500，佣金15%，每已住房晚变动成本100，贡献=20000−3000−4000=13000元；B直销40房晚同房价、无佣金、同服务成本，贡献16000元。总贡献29000元，未扣固定成本，不称净利润。
若降低房价预计增加入住，需加入价格对原本会购买客人的降价损失，不能只算新增房晚收入。

## 当前交付字段

- `revenueBaseline`：可售100房晚，售出且实际入住80，题设房费40000元（已扣税费退款与非房费、未扣佣金）；入住80%，ADR500元，RevPAR400元。
- `demandSignals`：只有一个入住日汇总，没有预订快照、提前期或取消曲线，无法判断需求上升；下一次比较需同入住窗和同提前期。
- `channelContribution`：A渠道20000−15%×20000−40×100=13000元；直销20000−40×100=16000元。合计29000元贡献，固定成本未给，不称净利润。
- `pricingOptions`：现有样本支持检查渠道贡献差，不能推出统一提价幅度。需观察相同日期/房型的需求、取消及替代渠道，比较有限价格情景和原有订单的降价损失。
- `facts`：本例所有对象和数值为合成，来源是本页input对应字段；未提供的真实文档、观察日或外部事实均不补造。各已给单位、日期和条款版本按原字段保留。
- `limitations`：仅完成所示条件推导与文本分析；未连接实际业务系统、未验证真实来源，未执行外部变更。缺口及其影响已经分布到各领域输出。
- `handoff`：本页作为合成交付示范；实际任务按delivery-template和method.json交同名字段、原材料位置与逐项检查证据。将上述待核材料交当前调用方继续，不创建新的授权或业务状态。

以上覆盖当前合同全部必填字段；它是合成输入的完整交付演练，不是实际业务验收。

## 看起来完整但应拒收

```json
{
  "revenueBaseline": "80笔订单就等于80房晚，餐饮也算ADR。",
  "channelContribution": "渠道A入住率高，所以一定比直销利润好。"
}
```

混淆订单与房晚、总营收与房费，并忽略佣金及成本。

## 材料不全时仍能交什么

- `revenueBaseline`：先列订单、房晚及房费可用字段；可售房晚分母未确定，暂不报入住率或RevPAR。
