# 商品卖点必须能回到可核实的产品事实

这是本包的原创合成工作样例，用于说明专业步骤、完整交付和拒收条件。它不是真实客户成果，也不是模型效果评测；实际任务替换输入与约束，按当前标准独立核验。

## 合成资料

水杯标注600mL、304不锈钢内胆、杯盖可拆，售价和库存由当前商品系统提供；没有保温测试、婴幼儿适用测试或材质检测文件。先区分厂家标注、已测事实和待证 claims，不把材质词自动转成认证结论。

## 可用交付

factLedger列每条事实、来源、变体/SKU范围和缺口。titleOptions可突出“600mL容量”“可拆杯盖”等现有事实；sellingPoints把特征转成使用价值时标出推理限度，例如可拆结构便于逐部件清洁，仍需确认清洁方式。detailCopy按用途、规格、使用/清洁、包装及购买前须知组织，未知的尺寸、保温时间、认证和配件不填。

| 候选表达 | 判断与修正 |
| --- | --- |
| 600mL容量，杯盖可拆 | 本例资料支持，核对应SKU |
| 24小时保温 | 无测试条件和结果，删去或补证据 |
| 婴儿放心用、医用级 | 资料不支持，不由材质名推导 |
| 全网最低价 | 没有范围/时点与可核比较，不能使用 |

## 实施流程

先查字段与SKU变体，再对照图片、标题、详情和规格表，消除容量/颜色/配件冲突。价格、促销和库存读取当前来源，不写死进可复用Skill。平台禁限词与当地合规条件按当前渠道查证；单一国家指南只提供声明核查思路，不是全球合规认证。

## 验收

每个重要卖点有事实支撑，标题承诺与页面说明一致，限制在影响选择的位置可见，未确认信息进入openQuestions。转化率提升需真实实验，不由文案评分推导。图库/页面尚未生成时，交可用文案和图片需求，不给不存在的发布链接。

## 使用与来源边界

方法依据沿用本包 PROVENANCE.md 的已登记专业资料。上面的数字、场景和交付表是原创合成示例；来源列表不证明当前任务已联网取证。先读取 professional-method.md 确认适用范围，再将本例迁移到当前事实；无法验证的结论交明确缺口，不填写成功回执。
