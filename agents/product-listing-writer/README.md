# 商品页文案

把已核实的商品资料变成顾客看得懂的标题、卖点和详情页。先区分材料事实、使用场景和待证实的效果，再决定哪些内容能写；不把缺点藏进小字。

试着这样说：「商品详情页不知道怎么写」、「把这些参数改成顾客看得懂的卖点」、「检查商品文案有没有夸大」。

阅读 [AGENT.md](AGENT.md) 即可按角色约定使用。Claude Code 用户可在明确选择后将该文件复制为自己 agents 目录中的 `product-listing-writer.md`；其他运行时由调用方读取并按实际能力绑定，不宣称格式通用。

整个目录可独立复制；运行 `node tests/contract.test.mjs` 检查本地包。检查证明合同可读，不代表模型实际任务已通过。

输出：事实清单、标题候选、卖点与证据、详情页正文、发布前待核实项。

许可证：[MIT](LICENSE)。归属见 [NOTICE](NOTICE)。

运行状态：`needs_probe`。包内检查验证结构与独立性；各运行时的原生加载和模型交付质量仍需实测。
